# 전략 최적화 이력

이 문서는 OpenAI GPT-4o를 활용한 전략 최적화 과정과 결과를 기록합니다.

## 최적화 방법론

### 1. AI 코드 분석
- GPT-4o에게 전략 코드 전체를 전송
- 패배 거래 패턴 분석 요청
- 구체적인 파라미터 개선 제안 수집

### 2. 검증 기반 적용
- AI가 제안한 각 파라미터 변경을 개별적으로 백테스트
- 승률 또는 수익률이 개선된 경우에만 적용
- 실패한 시도는 기록하여 다음 반복에 피드백

### 3. 반복 최적화
- 동일 전략에 대해 여러 번 반복 최적화
- 이전 실패 기록을 AI에게 공유하여 새로운 접근법 유도

## Phase 3: 데이터 드리븐 5분봉 인트라데이 전략

기존 일봉 전략의 한계를 극복하고, 5분봉 데이터에서 직접 패턴을 발견하여 전략을 설계.

### 접근 방식

1. **데이터 마이닝** (`scripts/analyze_intraday_patterns.py`): 462종목 60거래일 5분봉 ~190만건에서 급등 직전 피처 추출
2. **OpenAI 전략 설계** (`scripts/design_intraday_strategies_with_ai.py`): GPT-4o에 피처 분석 결과 전달 → 전략 코드 생성
3. **V2 엔진 검증** (`src/backtest/intraday_engine_v2.py`): numpy 사전계산 기반 ~13초/462종목

### 핵심 발견: RSI 중립 필터

- **RSI 40-60 (중립 영역)**이 모든 전략의 핵심 성공 요인
- RSI 필터 없이는 동일 조건에서도 마이너스 수익
- SL=3%, TP=5% (손익비 1:1.67, 거래비용 감안 손익분기 승률 39%)

### Round 3 핵심 교훈

1. **파라미터 그리드서치 > GPT**: 직접 파라미터 테스트가 GPT보다 효과적
2. **시간대 변형이 가장 효율적**: 수익 전략 복사 + 시간만 변경 → 가장 큰 수익 추가
3. **check_exit_fast는 GPT로 불가**: GPT가 entry 조건까지 수정하여 트레이드 폭증
4. **RSI 중립 필터가 핵심**: 이것 없이는 어떤 조합도 수익 불가
