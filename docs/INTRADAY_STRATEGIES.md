# 분봉 단타 전략 상세 문서

5분봉 기반 데이터 드리븐 분봉 단타 전략 6개. 당일 진입/청산 (인트라데이).

## 시스템 개요

### 데이터
- **DB**: PostgreSQL `ohlcv_intraday` 테이블
- **규모**: 5분봉 ~1,891,209건 (462종목, 60거래일)
- **종목**: 거래대금 상위 1000 중 5분봉 데이터 확보된 462종목

### 백테스트 엔진
- **V2 엔진** (`src/backtest/intraday_engine_v2.py`): numpy 사전계산 기반, ~13초/462종목
- **초기 자본**: 5,000,000원
- **최대 동시 포지션**: 3개
- **포지션 비중**: 30%
- **수수료**: 0.015% (매수/매도)
- **세금**: 0.23% (매도)
- **장마감 강제 청산**: 15:20

### 핵심 발견
- **RSI 40-60 (중립 영역)**: 모든 전략의 핵심 성공 요인. RSI 필터 없이는 수익 불가.
- **SL=3%, TP=5%**: 손익비 1:1.67. 거래비용(0.26%) 감안 시 손익분기 승률 = 39%
- **TP < 3%는 항상 실패**: 거래비용이 수익을 잠식

### IS/OOS 분리
- **In-Sample (IS)**: 처음 44거래일 (75%)
- **Out-of-Sample (OOS)**: 마지막 15거래일 (25%)
- 모든 전략은 IS에서 양수 AND OOS에서 IS 대비 -30% 이내 조건 충족

## 최적화 이력

### Round 1 (OpenAI GPT-4o 설계)
- 데이터 마이닝으로 급등 직전 피처 추출 → OpenAI에 전달 → 전략 코드 생성
- **결과**: 전략 1, 2, 3 생성 → 합계 +34.04%

### Round 2 (GPT-4o 반복 최적화 - 실패)
- check_exit_fast 시도 → IntradayPosition에 entry_bar_idx 미존재로 에러
- 새로운 시간대 전략 GPT 생성 → 모두 IS -5% ~ -24%
- **결과**: 전략 6만 +2.35%로 신규 채택

### Round 3 (파라미터 그리드 + 시간변형)
- **Phase 1 (파라미터 그리드서치)**:
  - 전략 3: ATR 0.005 + VWAP 이격도 1.002 → +8.24% → +10.84% (+2.6%)
  - 전략 6: ATR 범위 확장 + 양봉 완화 → +2.35% → +11.46% (+9.1%)
- **Phase 2 (check_exit_fast GPT)**: 모두 실패 (GPT가 entry 조건까지 변경)
- **Phase 3 (시간대 변형)**:
  - 전략 4 = 전략 1 → 13-15시: +3.87% (신규)
  - 전략 8 = 전략 3 → 9:30-12시: +14.24% (신규, 최고 수익)
- **Phase 4 (GPT 미세조정)**: 추가 개선 없음
- **최종**: +36.39% → **+66.21%** (+29.82% 개선)

### Round 4 (GPT-4o 수익률+승률 동시 개선)
- **목표**: 수익률 AND 승률 모두 개선 (둘 다 개선된 경우만 채택)
- **방법**: GPT-4o에 전략 코드 + 성과 데이터 전달 → 코드 수정 → IS/OOS 검증
- **전략 1**: Round 3에서 채택 → ATR 0.005→0.0045 + 거래량 필터 1.2x 추가
  - +16.62% → **+20.04%** (+3.42%), WR 47.5% → **48.9%** (+1.4%p)
- **전략 2~8**: GPT 제안 모두 기존보다 성과 하락 → 원본 유지
- **최종**: +66.21% → **+69.63%** (+3.42% 개선)

### 핵심 교훈
1. **파라미터 그리드서치 > GPT**: 직접 파라미터 테스트가 GPT보다 효과적
2. **시간대 변형이 가장 효율적**: 수익 전략 복사 + 시간만 변경 → 가장 큰 수익 추가
3. **check_exit_fast는 GPT로 불가**: GPT가 entry 조건까지 수정하여 트레이드 3-10x 폭증
4. **RSI 중립 필터가 핵심**: 이것 없이는 어떤 조합도 수익 불가
5. **거래량 필터가 추가 개선 가능**: 전략 1에서 10bar 평균 거래량 1.2x 필터 추가 시 승률+수익 동시 개선

## 기술 아키텍처

### 상속 구조
```
IntradayStrategy (ABC)          # src/strategies/intraday/base.py
├── precompute_day()            # numpy 배열로 하루치 지표 사전계산
├── check_entry_fast()          # 진입 신호 확인 (numpy 기반)
├── check_exit_fast()           # 청산 신호 확인 (numpy 기반)
└── (pandas 호환 메서드들)       # check_entry(), check_exit()
```

### base.py 제공 헬퍼
- `rsi_np(closes, period)`: RSI 계산 (numpy)
- `vwap_np(highs, lows, closes, volumes)`: VWAP 계산 (numpy)
- `rolling_mean_np(arr, window)`: 이동평균 계산 (numpy)
- `bollinger_bands_np(closes, period, std_dev)`: 볼린저밴드 (numpy)

### base.precompute_day() 기본 제공 지표
| 키 | 설명 |
|----|------|
| `close`, `open`, `high`, `low`, `volume` | OHLCV numpy 배열 |
| `timestamps` | 타임스탬프 리스트 |
| `n_bars` | 일중 bar 개수 |
| `rsi_14` | RSI(14) numpy 배열 |
| `vwap` | VWAP numpy 배열 |
| `vol_avg_20` | 20bar 거래량 이동평균 |

### 전략별 추가 사전계산 지표
| 지표 | 전략 | 설명 |
|------|------|------|
| `atr_10_pct` | 1,2,3,4,6,8 | ATR(10) / 종가 (변동성 비율) |
| `hours` | 1,2,3,4,6,8 | 시간(hour) 배열 |
| `bullish_candle` | 1,2,3,4,6,8 | 양봉 여부 (close > open) |
| `vol_ratio` | 2 | 현재거래량 / 20bar 평균거래량 |
| `avg_volume_last_5` | 6 | 직전 5bar 평균 거래량 |
