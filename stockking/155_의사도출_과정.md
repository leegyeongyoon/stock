## 3. 주요 내용 정리

### [02:27~04:20] 낙주 매매 판단 배경
- 알테오젠 당일 거래대금 1등 (1조 6,000억)
- 평소 낙주 매매는 1년에 한두 번만 하는 매우 드문 매매
- 항상 상승하는 주도주 위주로 매매하지만 이번은 특별 사례

### [04:20~07:00] 이상 신호 1: 지수 대비 독자 약세
- 11월 18일 코스닥 +0.6% 상승인데 알테오젠 혼자 -7% 급락
- 이전 음봉들은 시장과 함께 떨어진 것 → 외부 요인 하락은 금방 회복
- **지수 올라가는데 종목 혼자 급락 = 위험 신호**
- 이상 신호가 나온다고 100% 떨어지는 건 아니지만 주의 필요

### [07:00~10:00] 이상 신호 2: 과열 후 급등 종목의 급락
- 알테오젠 5만 원대부터 안 쉬고 계속 상승 → 급하게 오른 종목은 급하게 떨어짐
- 11월 18일 이후에도 장대음봉 연속
- 키트루다 호재에도 불구하고 시가 +7% 갭상승 후 종가 -7%로 마감

### [10:00~16:00] 낙주 매매 진입 조건
- 대형주 + 거래대금 1조 이상 + 낙폭 과대 + 단기 바닥 신호
- 차트만 보고 RSI 등으로 판단하는 것은 의미 없음
- 종목의 가치와 수급, 시장 상황을 종합적으로 판단해야 함

### [16:00~24:09] 매매 실행 과정
- 하락 과정에서 분할 매수
- 거래대금이 1조 이상 터지면서 반등 기대
- 수익 실현 후 이탈 - 낙주 매매는 빠르게 수익 확정이 핵심

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 이상 신호 포착 | 지수 상승 시 종목만 급락하면 위험 신호 |
| 외부 요인 vs 내부 요인 | 시장과 함께 떨어진 하락은 회복 빠름, 종목 자체 하락은 위험 |
| 낙주 매매 조건 | 대형주 + 거래대금 1조 이상 + 종합 판단 시에만 극히 드물게 실행 |
| 과열 후 급락 경계 | 안 쉬고 급등한 종목은 급락 가능성 높음 |
| 빠른 수익 확정 | 낙주 매매는 반등 시 빠르게 수익 실현 |

## 6. 명언/핵심 문장

> "차트만 보고 RSI가 어떻고 이래서 샀다 이런 것은 말이 안 된다고 생각합니다"

> "시장은 올라가는데 종목 혼자서 7% 떨어진 것은 되게 주의해야 될 신호입니다"

> "아무리 가치가 있는 회사라고 해도 급하게 오른 것은 급하게 떨어질 때가 분명히 있습니다"

## 7. 실전 적용 체크리스트

- [ ] 보유 종목이 지수 대비 독자 약세인지 매일 체크하기
- [ ] 지수와 함께 떨어진 하락인지, 종목 자체 하락인지 구분하기
- [ ] 급등한 종목은 과열 여부 반드시 확인하기
- [ ] 낙주 매매는 극히 드물게, 조건 충족 시에만 실행하기
- [ ] 낙주 매매 시 빠르게 수익 확정하는 원칙 지키기
