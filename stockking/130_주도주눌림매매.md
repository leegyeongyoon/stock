## 3. 주요 내용 정리

**[00:00~01:09] 수급 분산 장세 진단**
- 특정 테마로 수급이 몰리지 않고 여러 테마로 분산되는 날이 많았음
- 2월 29일 기준: 기아(자동차), 유진스펙(신규주), 우리기술투자(가상화폐), 폴라리스오피스(AI) 등 수급 흩어짐
- 수급 분산일에는 다른 종목에 수급을 뺏겨 윗꼬리 달고 하락하는 경우 빈번

**[01:09~02:40] KRX 정보 데이터 시스템 활용법**
- KRX 정보 데이터 시스템 -> 쉽게 보는 통계 -> 순위 통계 -> 거래 상하위 50 종목
- 거래대금과 등락률 위주로 분석
- 2월 28일: 2차전지(에코프로BM, 미래나노텍)와 반도체(주성엔지니어링, 한미반도체)로 수급 분산

**[02:40~04:05] 전일 종가 눌림매매 - 미래나노텍 사례**
- 주성엔지니어링: 다음날 갭 하락 -> 공략하지 않음 (갭 하락 종목은 패스)
- 미래나노텍: 다음날 4% 갭 상승 -> 전일 종가 근처에서 눌림매매 실행
- 전일 종가 근처가 강력한 지지선으로 작용, 터치 시 반등 확률 높음
- 확실한 대장주가 아니면 적당히 반등 시 정리

**[04:58~07:13] 전일 종가 눌림매매 - 알테오젠 사례**
- 2월 26일: 알테오젠 개별 이슈로 19% 상승 + 거래대금 1조 2천억
- 다음날 약 2% 갭 상승 -> 전일 종가 근처에서 매수
- 추가 이탈 시 추가 매수, 반등 시 분할 매도
- 하루에 전일 종가 근처 터치할 때마다 반복 매매 가능
- 손절 기준: 전일 종가 대비 -1% 이탈 후 빠르게 회복 못하면 빠르게 손절

**[07:21~08:10] 핵심 정리**
- 당일 확실한 대장주가 보이면: 장대양봉 매매법으로 큰 수익
- 확실한 종목 없는 날: 전일 대장주 눌림매매로 리스크 적은 매매
- 종목이 보이지 않는 날에는 매매를 절제하고 쉴 수 있어야 수익금을 지킬 수 있음

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 전일 종가 눌림매매 | 전일 장대양봉 대장주가 다음날 갭상승 후 전일 종가 근처까지 눌릴 때 매수 |
| 갭 하락 종목 배제 | 다음날 갭 하락으로 시작하는 종목은 공략하지 않음 |
| 손절 기준 | 전일 종가 대비 -1% 이탈 후 빠르게 회복 못하면 즉시 손절 |
| 분할 매도 | 반등 시 분할 매도로 수익 실현 |
| 매매 절제 | 확실한 종목 없는 날에는 쉬는 것도 전략 |

## 5. 종목 / 섹터 분석

| 종목명 | 테마/섹터 | 매매 포인트 | 비고 |
|--------|-----------|-------------|------|
| 미래나노텍 | 2차전지 | 전일 24% 상승 -> 다음날 갭상승, 전일종가 눌림매매 | 확실한 대장이 아니어서 짧게 매매 |
| 주성엔지니어링 | 반도체 | 장대양봉 후 갭 하락 -> 공략 안 함 | 갭 하락 배제 원칙 |
| 알테오젠 | 바이오(개별) | 전일 19% 상승, 거래대금 1.2조 -> 다음날 전일종가 눌림매매 | 하루 3번 반복 매매 |
| QRT | 반도체/HBM | 상한가 풀렸을 때 매수 -> 많이 밀려서 종가 매도 | 오버나잇 안 함 |

## 6. 명언 / 핵심 문장

> "전일 종가 근처는 강력한 지지선으로 작용할 때가 많아서 눌림 매매를 활용하고 있습니다."

> "당일 확실한 대장주가 보이지 않는 날에는 전일 대장주를 눌림에 매매하는 방법도 리스크가 적은 매매법입니다."

> "수익을 내는 것도 물론 중요하지만 종목이 보이지 않는 날에는 매매를 절제하고 쉴 수 있어야 쌓아온 수익금을 지키고 손실을 보지 않을 수 있습니다."

## 7. 체크리스트

- [ ] KRX 정보 데이터 시스템에서 전일 거래대금 상위 종목 확인하고 있는가
- [ ] 수급이 분산된 날인지, 특정 테마에 집중된 날인지 판단하고 있는가
- [ ] 갭 상승 종목과 갭 하락 종목을 구분하여 공략 여부를 결정하는가
- [ ] 전일 종가 근처를 지지선으로 활용한 눌림매매를 실행하고 있는가
- [ ] 전일 종가 대비 -1% 이탈 시 빠른 손절 원칙을 지키고 있는가
- [ ] 확실한 종목이 없는 날 매매를 절제하고 쉴 수 있는가
- [ ] 장 마감 직전 완만한 하락은 공략하지 않는 원칙을 지키는가
