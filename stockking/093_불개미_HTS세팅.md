# 093. 불개미 HTS 세팅 사용법 풀공개

## 1. 영상 개요

- **채널명:** 대왕개미 홍인기
- **업로드일:** 2025-07-24
- **영상 길이:** 27분 30초

## 3. 주요 내용 정리

### [00:00~02:00] 모니터 및 기본 세팅 소개
- 43인치 필립스 고해상도 모니터 1대 사용 (불개미 기준)
- 홍인기는 서브 모니터 추가 사용 (뉴스, 인터넷 검색용)
- 필요한 창만 최소한으로 배치하는 것이 핵심

### [02:00~04:00] 실시간 조회 순위 (화면번호 0198)
- 키움증권 사용자 기반 검색 순위 → 수급 쏠림 파악용
- 테마 전환 시점 빠르게 포착 가능 (스테이블코인 → 상법 개정 등)
- 내동매매의 원흉이 될 수 있어 초보는 안 띄우는 것 추천
- 30초 간격 업데이트, 돈의 흐름 추적 참고자료로 활용

### [04:00~06:00] 조건 검색 (화면번호 0156)
- 분봉상 30억 이상 거래대금 터지는 종목 알림
- 시장 상황에 따라 20억~30억으로 기준 조정
- 돈의 흐름 추적이 핵심 목적

### [06:00~08:00] 선물 지수 차트 (화면번호 0603)
- 왼쪽 상단: 선물 지수 차트 (코스피가 아닌 선물!)
- 오른쪽: 코스닥 차트
- 선물이 코스피의 선행지표 → 몇 초 빠르게 반영
- 미장 선물(인베스팅닷컴) 반드시 동시에 열어둘 것

### [08:00~15:00] 일봉/분봉 차트 배치
- 1분봉과 일봉은 "한 몸" → 두 개를 동시에 확인
- 일봉으로 자리 확인 → 분봉으로 타점 진입
- 불개미는 빠르게 종목 포착, 홍인기는 확실한 종목에 집중

### [15:00~27:00] 매매 스타일 비교 및 기타 창
- 불개미: 매매 횟수 많고 빠른 진입 스타일
- 홍인기: 하루 1~2종목 집중, 종가까지 갈 종목만 선별
- 호가창, 체결창, 잔고창 등 기본 창 구성 설명
- 누적 거래대금 확인의 중요성 강조

## 4. 핵심 매매 전략/교훈

1. **선물 차트를 반드시 열어라** - 코스피 차트가 아닌 선물 차트가 선행지표
2. **일봉+분봉 동시 확인** - 일봉으로 자리, 분봉으로 타점
3. **실시간 조회순위는 양날의 검** - 숙련자는 테마 전환 포착용, 초보는 내동매매 유발
4. **미장 선물(나스닥) 필수 모니터링** - 번지점프 나오면 국장 하락 가능성 높음
5. **불필요한 창 최소화** - 꼭 필요한 창만 배치하여 집중력 유지
6. **조건검색으로 돈의 흐름 추적** - 분봉상 일정 금액 이상 거래대금 알림 설정

> "1순위는 분봉창이고, 2순위는 일봉. 일봉하고 1분봉 두 개는 한 몸이라고 나는 보거든."

> "코스피 차트보다는 당연히 선물 차트를 열어 두셔야 됩니다. 선물이 미래 가격을 미리 반영하는 거기 때문에."

> "이걸로 매매하면 안 돼. 이건 참고용이지. 돈의 흐름이 어디로 이동하는가 보는 창고형 자료로 쓰고 있습니다."

> "종가까지 고가가 될 거라고 드는 생각이 드는 종목만 하려고 하는 편입니다."
