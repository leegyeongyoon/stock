# 213. 상장만하면 따상간다

2023년 1월 공모주 시장 활황 분석 영상. 오브젠 따상, 미래반도체 따상 등을 사례로 공모주 시장 분위기와 꿈비 청약 분석을 다루는 짧은 영상이다.

## 2. 핵심 키워드 (태그)

`#공모주` `#따상` `#꿈비` `#미래반도체` `#오브젠` `#유통물량` `#기관경쟁률` `#외국인매수` `#AI관련주` `#챗GPT`

## 3. 주요 내용 정리

- **[00:00~00:30]** 공모주 시장 활황
  - 오브젠 따상 기록 (청약 경쟁률 6:1도 안 됨)
  - MS의 OpenAI 투자 -> ChatGPT/AI 관련주 급등 시장
  - 신규 상장주에 관심 쏠리며 따상

- **[00:25~00:36]** 미래반도체 사례
  - 상장일 따상 + 다음날 24% 추가 상승
  - 1년 만에 이렇게 쉽게 따상 가는 시장

- **[00:36~00:55]** 시장 분위기 분석
  - 외국인 1월 초부터 대량 매수 -> 시장 분위기 개선
  - 유통물량 과다/인기 없는 공모주 아니라면 묻지마 청약 가능

- **[00:55~01:32]** 꿈비 청약 분석
  - 공모가 5,000원, 기관 경쟁률 1,547:1, 확약 12%
  - 유통가능물량 공모가 기준 100억 미만 (매우 적음)
  - 보통 200억 이하면 따상 확률 높음
  - 시장 분위기와 맞물려 공모가 대비 큰 상승 예상

## 4. 핵심 매매 전략

1. **유통물량 체크**: 200억 이하면 따상 확률 높음, 100억 미만은 매우 유리
2. **기관 경쟁률/확약 비율**: 1,000:1 이상 + 확약 10% 이상이면 양호
3. **시장 분위기 연동**: 외국인 순매수 유입 + AI 테마 등 트렌드와 연계
4. **묻지마 청약 타이밍**: 시장 분위기가 꺾이기 전까지는 청약 적극 참여
5. **신규 상장주 + 테마 결합**: AI/ChatGPT 등 테마와 연결된 신규주가 특히 강세

|------|------|------------|

## 6. 명언 / 인사이트

> "유통물량이 너무 많거나 정말 인기가 없는 공모주가 아니라면 당분간은 거의 묻지마 청약에 들어가도 상장일에 수익을 내고 나올 수 있을 것 같습니다."
