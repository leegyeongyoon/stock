## 3. 주요 내용 정리

**[00:15~02:27] 매매 원칙의 중요성 + 초보 시절 실수**
- 본인만의 확실한 매매 원칙이 있어야 주식시장에서 장기간 생존 가능
- 과거 실수: 좋아보이는 종목 매수, 자금관리 원칙 부재, 뉴스 따라 급등주 추격매수, 후발주 매수 후 손실
- 수익만 생각하고 잘못됐을 때 손절 기준을 세우지 않아 낭패

**[02:27~04:14] 구독자들의 흔한 실수 2가지**
- 실수 1: 강한 테마 대장주가 아닌 단순 거래대금 많은 종목 or 상승률만 높은 종목 매수 -> 고점 물림
- 프로그램 매매 하나에만 꽂혀 전체를 보지 못하는 문제
- 실수 2: 손절을 못 함 -> "한번 올려주겠지" 심리 -> 시드 소진

**[05:07~06:14] 원칙 1 - 시장 주도 테마 대장주 공략**
- 동해 석유 이슈 사례: 대장주 한국석유 vs 후발주 흥구석유
- 대장주는 떨어질 때 덜 떨어지고, 올라갈 때 더 크게 상승
- 같은 테마주들을 참고하며 매매 가능 -> 성공 확률 상승
- 후발주는 대장주보다 대부분 약한 흐름 -> 불리한 매매

**[06:17~07:59] 원칙 2 - 손절을 못 하면 주식을 그만둬야 한다**
- 한미반도체 사례: 손절 자리에서 못 팔아 큰 손실 + 초전도체 테마 기회 놓침
- 손절 못하면: 해당 종목 큰 손실 + 새 기회 기회비용 상실 + 심리 붕괴 -> 연쇄 악순환
- 단기 매매 종목은 기다린다고 올라가는 것이 아님

**[08:01~09:12] 원칙 3 - 자금 관리를 철저히**
- 수익 복리 욕심으로 금액을 한번에 크게 늘리면 손절 불가능 -> 엄청난 손실
- 1천만원 -> 1100만원 -> 1200만원: 느낄 수 없을 정도로 서서히 증액
- 1천만원에서 한번에 2천만원으로 늘리면 한번 잘못될 때 전액 상실 가능

**[09:12~10:10] 최종 정리 및 당부**
- 손실 시 복기하여 원인 분석 -> 본인만의 매매 원칙 수립
- 확실한 매매 원칙만 잘 지켜도 장기간 꾸준히 수익 가능

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 대장주 공략 | 시장에서 제일 센 테마의 상승률 1위 종목만 매매 |
| 확실한 손절 | 기준에 맞지 않으면 칼같이 손절, 손절 못하면 퇴장 |
| 자금 관리 | 감당 가능한 금액만 투입, 증액은 서서히 진행 |
| 후발주 배제 | 2등주, 후발주는 대장주보다 구조적으로 불리 |
| 뇌동매매 방지 | 확률 낮은 매매를 반복하면 단타에서는 금방 파산 |

## 5. 종목 / 섹터 분석

| 종목명 | 테마/섹터 | 매매 포인트 | 비고 |
|--------|-----------|-------------|------|
| 한국석유 | 석유/가스(동해석유) | 대장주 - 3일간 덜 떨어지고 더 크게 상승 | 대장주 우위 사례 |
| 흥구석유 | 석유/가스(동해석유) | 후발주 - 대장주 대비 약한 흐름 | 후발주 열위 사례 |
| 한미반도체 | 반도체 | 손절 못해서 큰 손실 + 초전도체 기회 놓침 | 손절 실패 사례 |

## 6. 명언 / 핵심 문장

> "시장에서 제일 센 테마의 대장주는 후발주보다 강한 흐름을 보여줄 수밖에 없기 때문에 시장에서 제일 센 테마 대장주를 매매 종목으로 선정했을 때 높은 확률로 수익을 낼 수 있었습니다."

> "손절을 못 하면 그 종목으로도 되게 크게 손실이 나고 새로운 기회도 잡지 못해서 기회 비용까지 날리고, 그렇게 되면 심리가 완전히 무너져 버려서 계속 매매가 꼬일 수 있습니다."

> "매매하는 금액을 늘리고 싶다면 한 번에 크게 늘리는 것이 아니라 정말 내가 느낄 수 없을 정도로 서서히 올려 나가야 합니다."

## 7. 체크리스트

- [ ] 당일 시장에서 제일 센 테마의 대장주를 찾아서 공략하고 있는가
- [ ] 거래대금만 많은 종목이나 상승률만 높은 종목에 무분별하게 진입하지 않는가
- [ ] 프로그램 매매 등 하나의 지표에만 의존하지 않고 종합적으로 판단하는가
- [ ] 손절 기준을 사전에 정하고, 기준 도달 시 칼같이 손절하는가
- [ ] 뇌동매매를 하지 않고 확률 높은 자리에서만 진입하는가
- [ ] 감당 가능한 금액만 주식 계좌에 넣어두고 매매하는가
- [ ] 매매 금액 증액 시 서서히 (10% 이내) 늘려가고 있는가
- [ ] 손실 발생 시 원인을 분석하고 복기하고 있는가
