## 3. 주요 내용 정리

### 체크포인트 1: 지수 (00:00~02:00)
- **코스닥 지수가 20일 이동평균선 위에 있는지 확인**
- 20일선 위 = 강세장 → 공격적 매매 가능
- 20일선 아래 = 약세장 → 보수적 매매 또는 관망
- 지수 확인이 모든 매매 판단의 출발점

### 체크포인트 2: 시황 (02:00~03:30)
- 전일 미국장 동향, 야간선물, 환율, 글로벌 이슈 체크
- 시황이 나쁘면 아무리 좋은 종목이라도 하락 압력 받음
- 국내 뉴스와 정책 변동 사항도 확인 필수

### 체크포인트 3: 거래대금 (03:30~05:00)
- **코스닥 전체 거래대금이 중요한 지표**
- 거래대금이 높을수록 시장에 돈이 몰리고 있다는 신호
- 거래대금이 낮으면 유동성 부족으로 매매가 어려움
- 10조원 이상이 기준선

### 체크포인트 4: 상승률 (05:00~06:00)
- 당일 상승률 상위 종목을 통해 시장의 관심 테마 파악
- 상한가 종목 수, 상승률 상위권의 테마 집중도 확인
- 테마가 뚜렷하게 형성되고 있는지 판단하는 핵심 지표

### 체크포인트 5: 시가총액 (06:00~07:30)
- **적정 시가총액 범위: 3,000억 ~ 10조원**
- 시총이 너무 작으면(3,000억 미만) 세력 놀이 가능성, 변동성 과다
- 시총이 너무 크면(10조 초과) 단타로 큰 수익 기대 어려움
- 중형주(3,000억~2조) 구간이 단타에 가장 적합

### 체크포인트 6: 끼 (07:30~09:00)
- **끼 = 해당 종목의 과거 최고 상승률 (잠재 폭발력)**
- 과거에 20~30% 상승 이력이 있는 종목은 끼가 높음
- 끼가 없는 종목(과거 5~7%만 오른 종목)은 당일에도 크게 오르기 어려움
- 끼를 기준으로 목표 수익률과 매도 타이밍 설정 가능

### 체크포인트 7: 수급 (09:00~10:30)
- 프로그램 매매(기관/외국인) 순매수 확인
- 수급이 들어오는 종목 = 큰 손들의 관심 → 상승 모멘텀
- 수급이 빠지는 종목 = 매도 신호
- HTS에서 실시간 프로그램 수급 체크 필수

### 체크포인트 8: 차트 위치 (10:30~12:33)
- **일봉 차트 먼저 보고 → 분봉으로 세밀하게 진입**
- 일봉상 신고가 영역에 있는 종목 선호 (저항선 없음)
- 바닥권에서 올라오는 종목보다 신고가 돌파 종목이 안전
- 분봉에서 매수 타이밍(눌림목, 돌파 시점) 결정
- **8가지 체크포인트를 모두 동시에 확인해야 함** (하나라도 빠지면 위험)

## 4. 핵심 매매 전략/교훈

### 전략 1: 8가지 체크 동시 충족 원칙
- 지수 + 시황 + 거래대금 + 상승률 + 시총 + 끼 + 수급 + 차트위치
- 8가지 중 하나라도 불충족이면 매수 보류
- 모두 충족될 때만 매수 → 승률 극대화

### 전략 2: 끼 기반 목표 수익률 설정
- 과거 최고 상승률 근처를 목표 매도 구간으로 설정
- 끼가 20%인 종목 → 15~18% 부근에서 분할 매도 시작
- 끼를 모르면 언제 팔아야 할지 판단 불가

### 전략 3: 일봉 → 분봉 순차 분석
- 일봉으로 큰 추세와 차트 위치(신고가, 저항선 등) 확인
- 분봉으로 구체적 진입 타이밍 결정
- 분봉만 보고 매매하면 큰 추세를 놓칠 수 있음
