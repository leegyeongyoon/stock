# 146. 불개미&홍인기 주도주 매매의 비기를 공개합니다

## 1. 영상 개요

## 3. 주요 내용 정리

### [00:29~02:08] 2025년 수익 공개
- 2023~2024년 합산 약 14억 수익
- **2025년 15억 이상** (계좌 3개: 8.4억 + 5.5억 + 1.3억)
- 핵심 성장 요인: **중요한 타점에 비중 배팅을 더 잘하게 됨**

### [02:08~05:04] 비중 관리의 핵심 (HCJ중공업 사례)
- 종목별 최대 매수 가능 금액 먼저 정하기 (소형주 1억 이하, 초대형주 30억까지)
- 1번 타점(초기): 3억대 매수 / 2번 타점(후기): 1억 넘는 금액
- 1번에 큰 비중 → 고가에 일부 실현 → 전체 수익 마감

### [05:04~07:26] 비중을 크게 실을 수 있는 타이밍
- **주도 테마 대장주라고 판단되는 완전 초기**에만 큰 비중
- 대략 9시~9시30분: 방향성 찾는 시간 (변동성 심함)
- 9시30분 이후: 주도 테마와 대장주가 보이기 시작
- 이 초기 시점에 가장 큰 비중으로 진입

### [07:26~09:27] 빠른 포착 시의 비중 관리
- 9시 이전에 주도주 될 것 같은 종목 발견 시 → **낮은 비중으로 선진입**
- 빠른 시간 큰 비중 = 변동성 리스크 큼
- 확인 후 추가 매수하되, 초기보다 낮은 비중

### [09:27~12:09] 콘텐츠 및 도구 소개
- 네프콘 평생소장 USB (기초 열강 + 특강 12강 + 스페셜 3강)
- 주도주 탐색 어플 '황금키' 개발

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 종목별 최대 비중 설정 | 시총, 거래대금, 끼, 변동성 종합 고려하여 최대 매수 금액 결정 |
| 초기 큰 비중 진입 | 주도 테마 대장주 확인 초기에 최대 비중 투입 |
| 시간대별 비중 차등 | 초기 타점(큰 비중) → 후기 타점(낮은 비중) |
| 빠른 포착 시 소비중 | 확인 전 선진입은 낮은 비중으로만 |
| 9시30분 기준 | 대략 9시30분 전후로 당일 주도 테마와 대장주 판단 |
