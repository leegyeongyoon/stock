## 3. 주요 내용 정리

### [00:00~04:00] D+0 매수 타이밍
- 장 초반~중반에 주도 테마 대장주 확인
- 장대양봉 형성 과정에서 눌림 시 매수
- 상한가 근처에서 1차 수익 실현

### [04:00~08:00] 오버나잇 판단
- 주도 테마 대장주 + 장대양봉 + 수급 = 오버나잇 조건
- 다음날 갭상승 확률 높음
- 갭하락 시 시초가에 즉시 매도

### [08:00~11:00] D+1 매매법
- 갭상승 후 전일 종가까지 조정 → 지지 확인 후 매수
- 반등 시 수익 실현
- 전일 종가 이탈 시 손절

## 4. 핵심 매매 전략/교훈

1. **D+0: 장대양봉 형성 과정에서 눌림 매수** - 급하게 쫓아가지 말 것
2. **오버나잇 조건 3가지** - 주도 테마 대장주 + 장대양봉 + 수급
3. **D+1: 전일 종가 = 지지선** - 조정 시 반등 매매 포인트
4. **갭하락 시 시초가 즉시 매도** - 예상 빗나감 인정
5. **매도 타이밍: 목표가 도달 or 흐름 꺾일 때** - 욕심 부리지 말 것
