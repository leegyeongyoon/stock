# 174. '이것' 보면서 주식단타, 매매가 쉬워집니다

- **영상 길이**: 8분 23초
- **조회수**: 3.6만

## 3. 주요 내용 정리

### 애매하면 매매하지 마라 (00:00~02:00)
- 마트에서 라면 10원 싼 곳 찾으면서 주식은 그냥 지르는 사람들이 많음
- 애매한 종목 매수 → 확신 없어서 조금만 흔들려도 손절 → 결국 손실
- 확실한 종목에서 나오는 매수 포인트는 어김없이 수익 확률이 높음
- "참는 습관"이 쌓이면 적어도 밥값은 할 수 있음

### 하나를 확실히 잘하라 (02:00~03:30)
- 이 매매, 저 매매 다 하려면 힘듦
- 자기 잘하는 매매 하나를 확실히 익힌 후 조금씩 넓혀가기
- 어설프게 많이 하는 것보다 잘하는 것을 확실히 파는 것이 성공 확률 높음

### 모니터/장비 세팅 (03:30~08:23)
- 홍인기: 필립스 43인치 1개 + 27인치 2개 = 총 3개 모니터
- 불개미: 43인치 1개로 충분, 화면 많으면 불필요한 정보 과다 → 뇌동매매 위험
- 데스크탑: 본체 기준 150~200만원이면 충분
- 초보자는 처음부터 많은 모니터 필요 없음, 필요할 때 추가

## 4. 핵심 매매 전략/교훈

1. **애매하면 매매하지 마라**: 애매한 건 수익 나도 얼마 못 먹고, 손실은 크게 봄
2. **확신 있는 종목에만 집중**: 참는 습관이 수익의 기본
3. **잘하는 매매 하나를 확실히 파라**: 이것저것 기웃거리지 말 것
4. **모니터 많다고 좋은 것이 아님**: 불필요한 정보 과다는 뇌동매매 유발
5. **장비 투자는 적절하게**: 데스크탑 150~200만원이면 매매에 충분
