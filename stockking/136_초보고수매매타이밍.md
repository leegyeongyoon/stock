## 3. 주요 내용 정리

**[00:00~02:12] 손절 vs 버티기 판단 기준**
- 종목에 대한 확신에 따라 다름: 확신 있으면 빠질 때 오히려 모아감
- 일봉이 부담스러운 자리에서 빨리 안 가면 즉시 정리 (1~10분)
- 처음 재료 나와서 장대봉이 처음 서거나 두 번째까지는 쉽게 팔면 안 됨
- 과열된 종목은 빨리 팔아야 함 (3~4% 급락 위험)
- 종목, 일봉, 시가총액에 따라 기계적 공식 없이 상황별 대응

**[02:20~04:07] 스몰캡(소형주) 매매 전략**
- 스몰캡(시총 3천억 이하): 변동성 극심, 1~2분 만에 5~10% 가능
- 비중을 현저하게 줄여야 함 (불개미: 맥시멈 1억)
- 빠른 시간 내 큰 등폭 -> 기회비용 절약 장점
- 초보자일수록 위험 -> 거래대금 터진 종목 위주가 안전
- 바지 사장(테마로 가볍게 올라가는 장)에서 스몰캡이 유리할 때 있음

**[04:07~05:58] 투자경고 / 단기과열 종목 대응**
- 투자경고: 종목이 세다는 의미이기도 함 -> 무조건 배제하지 않음
- 비슷한 종목 2개 있을 때: 투자경고 아닌 쪽 선택
- 단기과열 지정: 기본적으로 악재 (열 개 중 여덟 개 하락)
- 단기과열 2~3일차에 많이 빠진 종목 -> 종가 배팅으로 모아가기는 좋은 기법
- 경고/과열 종목 매매 시 비중 많이 줄여서 진행

**[05:58~06:49] 시가총액별 손절폭**
- 장이 좋다고 손절폭 넓히면 안 됨 (장 좋으면 올라가야 정상인데 안 올라가면 더 위험)
- 시가총액별로 다르게: 대형주 4.7% 손절은 부적절 (삼성전자 하루 최대가 4.7%)
- 테마주/중형주는 손절폭이 상대적으로 클 수 있음
- 장 안 좋을 때는 오히려 손절 준비를 더 빨리

**[07:00~08:50] 일정매매 시 선반영 판단 (핵심 꿀팁)**
- 일정매매에서 D-Day에 팔겠다는 생각은 완전히 잘못됨
- 핵심: 주가에 이미 반영됐는지 판단
- 일정 3일 남았어도 이미 3~4% 올랐으면 -> 팔아야 함 (이미 선반영)
- 일정 당일이라도 주가가 안 올랐으면 -> 그때까지 기다려야 함
- HLB 사례: 3만원에서 12.9만원까지 선반영 -> 발표 전 고점 찍고 하락

**[09:02~12:05] 비중관리와 멘탈의 관계 (핵심 인사이트)**
- 멘탈이 흔들린다 = 비중이 본인 그릇에 안 맞는 것
- 10억 매수 시: 3% 수익에 바로 챙김 (3천만원) + 손절 잘 안 나감
- 5억 매수 시: 7~8% 수익까지 가져감 (3,500만원) + 손절도 빠르게 가능
- 적게 사면: 수익 시 더 오래 보유(더 큰 수익) + 손절 시 빠르게 실행(더 적은 손실)
- 많이 산다고 많이 버는 것이 아님 -> 감당 가능한 비중이 가장 효율적
- 열 번 중 일곱 번 수익, 두세 번 손실로 계좌 망가지는 원인 = 과다 비중

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 확신별 보유기간 차등 | 확신 높으면 모아가기, 부담스러운 자리면 빠르게 정리 |
| 스몰캡 비중 축소 | 시총 3천억 이하는 비중 현저히 줄여 매매 |
| 단기과열 종가배팅 | 2~3일차 많이 빠진 테마주를 종가에 모아가기 |
| 선반영 판단 매도 | 일정 D-Day가 아니라 주가 선반영 여부로 매도 타이밍 결정 |
| 감당 가능 비중 | 멘탈 흔들리지 않는 비중이 수익/손실 모두에서 최적 |

## 7. 체크리스트

- [ ] 종목 확신도에 따라 보유 기간을 차등 적용하는가
- [ ] 일봉이 부담스러운 자리에서 빨리 안 가면 즉시 정리하는가
- [ ] 스몰캡 종목 매매 시 비중을 현저히 줄이고 있는가
- [ ] 투자경고/단기과열 종목 매매 시 비중을 축소하는가
- [ ] 단기과열 2~3일차 해제 시점을 종가배팅 기회로 활용하는가
- [ ] 일정매매에서 D-Day가 아닌 선반영 여부로 매도 판단하는가
- [ ] 시가총액별로 손절폭을 다르게 설정하는가
- [ ] 감당 가능한 비중으로 매매하여 멘탈을 유지하는가
- [ ] 과다 비중이 수익 조기 청산 + 손절 지연의 원인임을 인식하는가
