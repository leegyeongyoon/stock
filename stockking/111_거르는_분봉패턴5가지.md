## 3. 주요 내용 정리

### 패턴 1~2: 뉴스빵 패턴 & 깊은 눌림 패턴
- **뉴스빵 패턴:** 일봉 자리 체크 + 이미 주가 선반영 여부 확인 + 당일 주도 섹터 내에서만 매매
- **깊은 눌림 패턴:** 분봉상 모든 시장 참여자 심리가 무너진 상태 → 반등해도 매물 부담 과다 → 회피

### [01:00~03:00] 패턴 3: 끼 다온 패턴
- 종목마다 상승 맥시멈이 다름 (삼성전자 7%, 중소형주 20% 등)
- 끼의 80% 정도 도달 시 고점 경고
- 고점에서 최대 거래량 터지고 음봉 나오면 90% 고점 확정
- 포스코DX 예시: 15% 도달 → 끼 다 왔다고 판단 → 매수가 = 매도 원칙

### [03:05~04:40] 패턴 4: 3파동 패턴
- 1파동 → 눌림 → 2파동 → 눌림 → 3파동 후에는 추가 상승 확률 극히 낮음
- 3파동 완료 종목은 주도 대장주가 아닌 이상 눌림 매수 절대 금지
- 예외: 전날 상한가 갔던 주도 대장주급 종목은 3파동 이후에도 가능

### [04:40~09:30] 패턴 5: 가분수 패턴
- 양봉 4개 연속 + 마지막에 압도적 거래량 = 매도 신호
- 머리(거래량)가 몸(가격 상승폭) 대비 과도하게 큰 형태
- 고점에서 거래량 빵 터지면 거의 항상 고점
- 돌파하는 척해도 먹을 폭이 안 나옴 → 장기 관망 필요

## 4. 핵심 매매 전략/교훈

1. **뉴스빵 패턴: 일봉 자리 + 선반영 여부 + 주도 섹터 체크** - 뉴스만 보고 진입 금지
2. **깊은 눌림: 시장 심리 무너진 자리 접근 금지** - 반등해도 매물 벽
3. **끼 다온 패턴: 종목별 상승 맥시멈 파악 필수** - 80% 도달 시 매수가 = 매도
4. **3파동 완료 후 눌림 매수 금지** - 시간 낭비, 기회비용 낭비
5. **가분수 패턴: 압도적 거래량 + 고점 = 매도 신호** - 총알받이 금지

## 7. 실전 적용 체크리스트

- [ ] 매매 전 종목의 끼(상승 맥시멈) 일봉에서 확인 (최근 6개월~1년)
- [ ] 분봉상 3파동 완료 여부 확인 → 완료 시 추가 매수 금지
- [ ] 고점에서 최대 거래량 + 음봉 = 즉시 매도
- [ ] 양봉 4연속 + 압도적 거래량 = 가분수 패턴 → 매수 금지
- [ ] 뉴스 나온 종목은 일봉 자리 + 주도 섹터 여부 먼저 체크
