# 167. 주도테마 대장주 매일 알려드립니다

## 1. 영상 개요
NXT 대체거래소 출범 영향, 프리마켓/애프터마켓 대응법, 이재명 테마주(오리엔트전공) 사례, 하락장 보수적 매매 전략, 데일리테마/대왕개미브리핑 서비스를 소개하는 영상.

- **채널**: 대왕개미 홍인기
- **업로드일**: 2025-03-30
- **영상 길이**: 10분 23초
- **조회수**: 3.9만
- **URL**: https://www.youtube.com/watch?v=NXeXJ3rrmCk

## 3. 주요 내용 정리

### NXT 대체거래소와 시장 변화 (00:00~03:30)
- 대체거래소 출범으로 프리마켓(8시), 애프터마켓(오후 8시) 거래 가능
- 정규장 외 시간은 거래량 적어 아직 큰 영향 없음
- 장기적으로는 유동성 증가 효과 기대

### 이재명 테마주 매매 사례 (03:30~06:30)
- 오리엔트전공이 이재명 관련주로 강세
- 정치테마주는 변동성이 크므로 비중을 낮춰 매매
- 재료 소멸(대선일) 앞두고 보수적 접근 필요

### 하락장 보수적 매매 (06:30~10:23)
- 시장이 안 좋을 때는 매매를 줄이고 비중을 낮춰야 함
- 하락장에서는 수익 목표를 낮추고 손실 방어에 집중
- 데일리테마, 대왕개미브리핑을 통한 매일 주도테마 공유

## 4. 핵심 매매 전략/교훈

1. **프리/애프터마켓은 참고만**: 거래량이 적어 정규장 중심 매매
2. **정치테마주는 비중 10~20%로 제한**: 변동성이 크므로 리스크 관리 필수
3. **하락장에서는 매매 최소화, 비중 축소**: 보수적 대응이 계좌를 지킴
4. **재료 소멸 앞둔 테마는 보수적으로**: 이벤트 종료 후 급락 가능성
