# 109. 트럼프 관련주 '이렇게' 공략하세요

## 1. 영상 개요
- **한줄 요약:** 트럼프 당선 수혜주인 조선 테마 실전 매매 - 현대중공업 사전 매수, 현대힘스 상따, 한화오션 D+1 매매
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2024-11-10
- **영상 길이:** 9분 1초
- **원본 URL:** https://www.youtube.com/watch?v=8N3diIwL7gc

## 2. 핵심 키워드
`#트럼프당선` `#조선테마` `#현대중공업` `#현대힘스` `#한화오션` `#상따매매` `#주도테마대장주` `#신고가` `#대형주단타` `#오버나잇`

## 3. 주요 내용 정리

### [00:00~03:00] 조선 테마 매매 내역 공개
- 트럼프 당선 후 목요일/금요일 조선 테마 초강세
- 현대힘스 20%+ 상승, HD현대중공업 15% 상승
- 현대중공업을 대선 전 월요일에 미리 매수 (박스권 하단, 단기 수익 관점)

### [03:00~05:00] 조선 테마 집중 이유
- 우주항공(AP위성, HBM) vs 조선 테마 비교
- 조선 테마가 거래대금 훨씬 많고, 대형주가 20% 상승 = 테마 강도 압도적
- 가장 강력한 테마 한 가지만 집중 공략

### [05:00~09:00] 주도 테마 내 매매의 장점
- 장기 상승 추세 주도 테마 내 종목 = 호재 발생 확률 높음
- 신고가 근처 종목이 많은 테마 공략 시 수익 확률 상승
- 동일 테마 내 다른 종목 참고 가능 → 대응이 쉬움
- 바이오(알테오젠), 방산(한화에어로스페이스, 현대로템) 등도 신고가 근처

## 4. 핵심 매매 전략/교훈

1. **주도 테마 내에서 단기 수익 관점 선매수** - 조정 구간에서 미리 매수 후 이벤트 수혜
2. **가장 강력한 테마 한 가지에 집중** - 여러 테마 분산하지 말 것
3. **대형주도 상따 가능** - 테마 강도가 확실하면 대형주도 상따 관점으로 진입
4. **신고가 근처 종목이 많은 테마 선택** - 테마 지속성과 수익 확률 상승
5. **동일 테마 내 종목 참고하여 대응** - 대응 난이도 낮춤

## 5. 주요 종목/섹터 언급

| 종목/섹터 | 맥락 |
|-----------|------|
| HD현대중공업 | 대선 전 선매수 → 이틀 연속 장대양봉 |
| 현대힘스 | 당일 상따 → 오버나잇 → 갭상승 익절 |
| 한화오션 | D+1 눌림매매, 분할매수 후 반등 시 수익 실현 |
| AP위성 | 우주항공 테마 상한가 (비교 대상) |
| 알테오젠 | 바이오 대장주, 신고가 돌파 |
| 한화에어로스페이스 | 방산 대장주, 지속 신고가 달성 |
| 현대로템 | 방산 관련주, 신고가 근처 |

## 6. 명언/핵심 문장

> "항상 종목 선정을 할 때 최근에 시장을 주도했던 테마 내에서 매매하는게 정말 중요하고 신고가 근처에 있는 종목을 매매해야 수익 내기도 훨씬 수월합니다."

> "주도 테마 내에 있는 주식을 매수를 하면 그런 종목은 막 호재가 나올 때가 되게 많습니다."
