## 3. 주요 내용 정리

### [00:00~04:00] 코스피 신고가와 시장 상황
- 코스피 종가 기준 신고가 갱신 → 투심 좋아짐
- 하지만 매매 난발 금지 → 벌었다가 잃는 패턴 반복
- 거래량 증가 시 매매할 종목 많아져 내동매매 위험 증가

### [04:00~08:00] 매수 근거 확보의 중요성
- 일봉 자리, 프로그램 매수세, 섹터 분위기, 누적 거래대금 등 여러 근거 필요
- HJ중공업 예시: 8,000원 → 34,000원 상승, 조선 섹터 주도
- 고점에서는 매수 근거가 더 강해야 함

### [08:00~14:00] 고점에 물리지 않는 법
- 고점에서 매수한 종목이 안 갈 때 빠르게 인정하고 손절
- 후발주 흐름이 안 좋으면 대장주도 정리
- 비중 태우지 않기 → 실수 연쇄를 방지
- 추석 연휴 활용 공부 권장

## 4. 핵심 매매 전략/교훈

1. **신고가 돌파 = 매매 열심히가 아닌 선택과 집중** - 난발 금지
2. **매수 전 반드시 여러 근거 확보** - 일봉, 수급, 섹터, 거래대금
3. **고점 매수 시 안 가면 빠르게 인정하고 손절** - 미련 금지
4. **후발주 약세 → 대장주도 위험 신호** - 섹터 전체 흐름 확인
5. **연속 실수 시 비중 줄이기** - 손실 연쇄 방지
