## 3. 주요 내용 정리

**[00:18~01:14] 시장 리뷰 및 수급주 특징**
- 코스닥 소폭 상승, 20일선 위에서 유지 -> 매매하기 좋은 시장
- 최근 시장 특징: 수급주가 많음 (개인이 아닌 기관/외국인 대량 매수로 상승)
- 수급주는 주로 시가총액 조 단위 중대형 종목
- 외국인/기관이 꾸준히 사주므로 주가 흐름 안정적, 높은 비중 매수 가능

**[01:25~03:19] 주요 수급주 사례**
- 고영: 뇌수술 로봇 뉴스 -> 상한가 -> 한 주 내내 기관 꾸준 매수
- 제주반도체: 중국 스마트폰 보조금 뉴스 -> 상한가 -> 단기과열 지정 (30분마다 단일가 매매)
- HD현대미포: 조선 테마 강세로 신고가 돌파 시도 후 고점 저항
- 한화오션: 미국 군함 기대감으로 지속 상승
- 이수페타시스: 오라 인수 무산 뉴스 -> 외국인/기관 대량 매수 -> 28% 급등
- HD현대일렉트릭: 실적 미달 장대음봉 -> 외국인 대량 수급으로 역사적 신고가 돌파

**[03:56~05:34] 실전 매매 복기**
- HD현대일렉트릭: 고점 돌파 양봉 나올 때 눌림에 매수 -> 반등 시 매도
- 이수페타시스: 기관/외국인 수급 강한 흐름에서 눌림 위주 공략
- HD현대미포: 신고가 돌파 시도 날 신고가 이탈 목표 매매
- 알테오젠: 28~33만원 박스권 -> 수요일 수급 동반 박스권 돌파 매수 (너무 빨리 매도해 아쉬움)
- LS에코에너지: 저가에 매수 -> 상한가 진입 -> 다음날 갭하락 -> 아침 장초반 전량 정리

**[05:22~06:08] 오버나잇 실패 교훈**
- 오버나잇 종목은 다음날 강세 보여야 정상
- 전일 종가 이탈 후 빠르게 회복 못하면 강한 음봉 가능 -> 빠른 정리 필요

**[06:08~06:55] 시장 분위기에 맞춘 매매**
- 최근: 중소형주보다 외국인/기관 수급 동반 조 단위 종목 위주 상승
- 시장 분위기를 파악하고 거기에 맞는 매매가 중요

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 수급주 매매 | 외국인/기관 대량 매수 종목 위주로 안정적 매매 |
| 눌림매매 | 수급주의 고점 돌파 양봉 발생 시 눌림에 매수 -> 반등 매도 |
| 박스권 돌파 매매 | 외국인/기관 수급 동반 박스권 돌파 시 매수 |
| 시가총액 조 단위 집중 | 높은 비중 매수 가능, 주가 흐름 안정적 |
| 오버나잇 원칙 | 다음날 전일종가 이탈 + 빠른 회복 안 되면 즉시 정리 |

## 6. 명언 / 핵심 문장

> "기관 투자자는 한번 매수하기 시작하면 지속적으로 매수하는 경향이 강하기 때문에 기관의 대량 수급이 들어오는 종목은 지속적으로 관찰할 필요가 있겠습니다."

> "주도 테마 대장주라고 판단해서 오버나이트 한 종목의 경우 다음날에도 강세를 보여야 정상이지만 전일 종가 이탈해서 빠르게 회복하지 못하는 경우 강한 음봉이 나올 수 있으니 주의하셔야겠습니다."

> "항상 매매를 하실 때에는 전반적인 시장 분위기를 잘 파악하시고 거기에 맞게 매매를 하셔야 되겠습니다."

## 7. 체크리스트

- [ ] 외국인/기관의 매수 동향을 체크하고 있는가
- [ ] 시가총액 조 단위 수급주 위주로 매매하고 있는가
- [ ] 기관이 한번 매수 시작하면 지속 매수하는 경향을 활용하는가
- [ ] 수급주의 고점 돌파 양봉에서 눌림매매를 실행하는가
- [ ] 박스권 돌파 시 수급 동반 여부를 확인하는가
- [ ] 오버나잇 종목의 다음날 전일종가 이탈 시 빠르게 정리하는가
- [ ] 시장 분위기(중소형주 vs 대형수급주)를 파악하여 매매 스타일을 조정하는가
