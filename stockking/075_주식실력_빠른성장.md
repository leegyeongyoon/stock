# 075. 이런 사람은 주식실력이 빠르게 성장합니다

## 1. 영상 개요
개미원정대 포맷으로 22살 전업투자자 '불꽃개미'와 함께 아침 루틴, HTS 세팅, 실전 매매를 실시간 진행하며 빠르게 성장하는 투자자의 특징을 보여주는 영상.

- **채널**: 대왕개미 홍인기
- **업로드일**: 2025-03-20
- **영상 길이**: 25분 53초
- **URL**: https://www.youtube.com/watch?v=ZGKqhrpJU-Q

`#개미원정대` `#전업투자자` `#아침루틴` `#매매원칙적기` `#HTS세팅` `#현대로템` `#방산테마` `#윗꼬리종목` `#기계적손절` `#프로그램수급`

## 3. 주요 내용 정리

### [00:00~08:00] 아침 루틴과 HTS 세팅
- 장 시작 전 매매 원칙을 읽고 마음가짐 점검
- 미래에셋(데이트레이딩용) + 키움증권(오버나잇용) 두 계좌 병행
- HTS 세팅: 관심종목, 호가창, 지수, 프로그램/기관 수급, 미체결, 수익률, 분봉차트
- 거래대금 순위로 매매 종목 선택

### [08:00~14:00] 실전 매매 (현대로템 중심)
- 조선/방산 테마가 아침부터 강세 -> 현대로템 집중 매매
- 현대로템: 전일 윗꼬리 발생했지만, 시장 전체 약세 때문이지 종목 문제가 아님
- 프로그램 62만주(640억) 아침부터 강력 매수 -> 수급 좋음
- 9시 5분경 99,000원대에서 첫 매수 (평소보다 일찍 진입)

### [14:00~25:53] 매매 복기와 성장 포인트
- 대장주와 2등주, 3등주를 동시에 체크하여 비교
- 상승률이 더 센 쪽으로 매매 집중
- 손절 기준: 3% 이상 하락 시 기계적 손절
- 주식 시작 3개월 만에 원칙 체계를 잡은 점이 인상적

## 4. 핵심 매매 전략/교훈

1. **아침 루틴의 중요성**: 장 시작 전 매매 원칙을 읽고 종합시황 확인
2. **두 계좌 분리 운용**: 데이트레이딩 계좌와 오버나잇 계좌를 분리하여 리스크 관리
3. **윗꼬리 종목 판단법**: 종목 자체 문제인지 시장 전체 약세 때문인지 구분
4. **프로그램 수급 활용**: 아침부터 프로그램이 강하게 매수하는 종목은 상승 확률 높음
5. **기계적 손절 3%**: 어떤 상황에서도 3% 손실 시 기계적으로 손절
