2025년 7월 셋째 주 시장을 복기하며, 바이오(펩트론, 유한양행)와 2차전지(포스코퓨처엠) 주도 테마 대장주의 실제 매매 타점을 공개한다. 확신 있는 자리에서만 비중을 실어 매매하는 전략, 거래대금 상위 종목 분석을 통한 주도 테마 찾기 방법을 상세히 설명한다.

## 3. 주요 내용 정리

**[00:29~01:08] 주간 시장 리뷰**
- 코스닥 시장 강세, 코스피 횡보
- 그동안 코스피 위주 강세에서 상대적 저평가된 코스닥 종목들 위주 상승
- 주요 테마: 바이오(화요일, 목요일) + 2차전지(금요일)

**[01:10~05:06] 유한양행 매매 타점 (목요일)**
- 구글의 비만치료제 관련 메세라 투자 뉴스로 바이오 테마 형성
- 오전: 펩트론 vs 유한양행 수급 분산 -> 비중 실기 어려운 상황
- 매매 스타일: 애매할 때 매매 안 하고, 확신 있는 자리에서만 비중 집중
- 오후 2시경 유한양행이 확실한 대장주로 판정 -> 약 7억 5천만 원 매수
- 종가 근처 전량 매도 -> 4~5% 수익 (평균 약 3%)
- 빨리 매수하면 높은 수익률 가능하나, 예상과 다를 때 손절 리스크 존재
- 늦게 매수해도 잃지 않고 확률 높은 자리에 공략하는 것이 핵심

**[05:37~07:46] 포스코퓨처엠 매매 타점 (금요일)**
- 금요일 2차전지 테마가 주도 -> 대장주 포스코퓨처엠
- KRX 기준 약 5% 갭상승 시작 -> 아침 일찍 매수
- 매수 직후 수급 집중으로 한 번에 13% 급등
- 확신 있어 눌림에도 추가 매수로 수익 극대화 시도
- 예상치 못한 11:30 실적 발표(기대 미달) -> 흐름 꺾임
- 전략 변경: 오버나잇 대신 오후 분할 매도로 수익 실현
- 오전 매수 물량 약 10% 수익, 눌림 추가매수 물량은 본전 수준 정리

**[07:58~10:09] 주도 테마 대장주 찾는 방법**
- 키움증권 0186번 거래대금 상위 화면 -> 상위 20위 내 상승률 높은 종목 체크
- 같은 테마 종목이 여러 개 포진 -> 해당 테마가 주도 테마
- 테마 불분명 시: 0700번 종합시황 뉴스 창에서 종목 뉴스 키워드 확인
- 금요일 사례: 포스코퓨처엠, 에코프로BM, 태경BK, 에코프로, 포스코DX -> 2차전지 주도

**[10:09~13:20] 주도주 찾기 챌린지 / 카페 소개**
- 주식넘버원 네이버 카페에서 주도주 찾기 챌린지 운영
- 50거래일 참여 시 굿즈 제공 (모니터 스탠드, 매매원칙 비법 노트)

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 확신 매매 | 애매할 때 안 하고, 확실한 대장주가 결정되면 비중 집중 |
| 늦더라도 안전한 자리 | 빨리 사는 것보다 잃지 않는 자리에서 매수하는 것이 핵심 |
| 변수 대응 | 실적 발표 등 예상치 못한 변수 시 전략 변경 (오버나잇 -> 당일 정리) |
| 거래대금 상위 분석 | 거래대금 상위 20위 내 상승률 높은 종목의 테마 파악 -> 주도 테마 식별 |
| 뉴스 키워드 확인 | 종목의 테마를 모르면 HTS 뉴스 제목에서 키워드 확인 |

## 6. 명언 / 핵심 문장

> "매매 스타일상 저는 애매할 때 매매를 하는게 아니라 정말 확신이 있는 자리가 나온다면 그때 비중을 실어서 매매하고 확실한 기회가 올 때까지 기다리는 스타일입니다."

> "빨리 매수하는 것보다 조금 늦게 매수하더라도 잃지 않고 정말 확률 높은 자리에 공략을 하기 위해서 기다렸습니다."

> "뇌동 매매를 하지 않고 매매를 최소화해서 확률 높은 기회가 올 때까지 참는다면 이렇게 좋은 기회를 잡을 수 있습니다."

## 7. 체크리스트

- [ ] 거래대금 상위 20위 내 종목들의 테마를 파악하고 있는가
- [ ] 같은 테마 종목이 다수 포진한 것으로 주도 테마를 식별하는가
- [ ] 애매한 장에서 무리하게 매매하지 않고 기다릴 수 있는가
- [ ] 확실한 대장주가 결정된 후 비중을 실어 매매하는가
- [ ] 실적 발표 등 예상치 못한 변수에 전략을 유연하게 변경하는가
- [ ] HTS 뉴스 키워드를 활용하여 종목의 테마를 빠르게 파악하는가
- [ ] 뇌동매매 없이 확률 높은 자리에서만 진입하는가
