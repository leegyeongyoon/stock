# 154. 주식단타 수급 보는 방법 3가지

## 3. 주요 내용 정리

### [00:00~02:30] 지지/저항 가격 복습
- **4가지 지지/저항 가격:**
  1. 과거 고점 (일봉/분봉에서 확인)
  2. 라운드 피규어 가격 (만원, 2만원 등 딱 떨어지는 가격)
  3. VI 발동 가격 (시초가 대비 +/-10%)
  4. 당일 시초가 및 전일 종가

### [02:30~07:00] 초보 학생 매매 리뷰
- 초보개미: 5일 연속 수익(32,000원), 전고점 지지/저항 활용
- 화신 매매: 프로그램 매도로 하락 → 손절 → LX1에서 만회
- 한국석유: 지지/저항 없이 뇌동매매 → 적게 수익
- 디비하이텍: 대장주 판단 맞았으나 심리적으로 못 버팀

### [07:00~12:00] 수급 보는 방법 1: 투자자별 매매 동향
- 키움증권 0784번 화면으로 투자자별 매매 추이 확인
- 외국인 가집계 수량은 부정확 → 프로그램 매매로 정확히 확인
- 기관/외국인 수급 방향이 종목 상승의 핵심 동력

### [12:00~18:00] 수급 보는 방법 2: 프로그램 매매
- 프로그램 매수가 지속적으로 들어오는 종목은 상승 확률 높음
- 프로그램 매도 20~30억 이상이면 매매 자제
- 뉴스 발생 후 프로그램 매도가 줄어들면 매매 가능 신호
- 일봉 자리에 따라 프로그램 매도 허용 수준 달라짐

### [18:00~27:39] 수급 보는 방법 3: 거래원 분석
- 키움증권 대량 매수 = 개인 주도 = 고점 신호
- 모건스탠리 등 외국계 증권사 매수 = 지속 상승 가능
- 한투/신한/JP모건 = 단타 특성, 빠르게 이탈 가능
- 거래원별 특성을 파악하여 수급 판단

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 4가지 지지/저항 가격 | 과거 고점, 라운드 피규어, VI 발동, 시초가/종가 |
| 프로그램 매매 확인 | 프로그램 매수 지속 = 상승 신호, 매도 20~30억 이상 = 매매 자제 |
| 거래원 분석 | 키움 대량 매수 = 고점 경계, 외국계 매수 = 긍정적 |
| 대장주 판단 기준 | 거래대금, 등락률, 수급 종합적으로 확인 |
