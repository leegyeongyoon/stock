# 110. 시장이 급락할 때 단타 대응법

## 1. 영상 개요
- **한줄 요약:** 외부 변수(계엄령 등)로 시장 급락 시 주도주 반등 공략법과 보유 종목 대응 전략
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2024-12-04
- **영상 길이:** 7분 17초

## 3. 주요 내용 정리

### [00:00~03:00] 급락 후 가장 먼저 반등하는 종목
- 시장 급락 후 반등 시 가장 먼저 상승하는 종목 = 많이 떨어진 종목이 아니라 최근 가장 강했던 종목
- 거래대금 상위(0186번 화면)에서 상승률+거래대금 높은 종목 확인
- 이수페타시스: 27% 상승, 6천억 거래대금, 기관 160만주 매수

### [03:00~05:00] 급락장 매매 실전과 선물 동향 확인
- 시초가 -1% 갭하락 → 10분 후 8.8% 상승
- 시장 추가 하락 우려 시 0782번 시간대별 투자자 화면에서 선물 동향 확인
- 8시 45분 코스피 선물 개장 → 외국인 매수 2천억 = 크게 걱정할 상황 아님

### [05:00~07:00] 오버나잇 종목 대응 + 소외주 대응
- 주도주 오버나잇 상태에서 외부 변수 발생 → 손절하지 않고 반등까지 버티기
- 이수페타시스 5억 오버나잇 → 갭하락에도 9.9% 수익
- 소외주 보유 시 → 급락 때 소외주 손절하고 주도주로 갈아타기

## 4. 핵심 매매 전략/교훈

1. **급락 후 최근 가장 강했던 종목이 가장 먼저 반등** - 많이 떨어진 종목이 아님
2. **거래대금 상위 + 장대양봉 + 기관 수급 = 주도주 판단** - 전일 기준 확인
3. **선물 동향으로 시장 방향 사전 확인** - 8시 45분 코스피 선물 외국인 동향
4. **주도주 오버나잇이면 급락에도 버티기** - 주도주는 반등 시 가장 먼저 상승
5. **소외주 보유 시 급락이 오히려 주도주로 갈아탈 기회** - 위기를 기회로 전환

> "주도주를 가지고 있는 상황에는 이런 외부 변수가 발생해도 크게 걱정할게 없습니다."
