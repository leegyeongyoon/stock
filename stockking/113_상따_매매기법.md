# 113. 강력한 주도주 공략 상따 매매 기법

## 1. 영상 개요
- **한줄 요약:** 원익홀딩스 로봇테마 상한가 따라잡기 실전 매매 - 미장 폭락에도 주도주 공략으로 수익, 해지성 테마 회피 이유
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2025-10-13
- **영상 길이:** 10분 12초
- **원본 URL:** https://www.youtube.com/watch?v=6j8cRRLW-hU

## 2. 핵심 키워드
`#상따매매` `#상한가따라잡기` `#원익홀딩스` `#로봇테마` `#미장폭락` `#장전시간외` `#D+0매매` `#D+1매매` `#해지성테마` `#비중관리`

## 3. 주요 내용 정리

### [00:00~03:00] 로봇 테마 대장주 상따 매매
- 추석 연휴 소프트뱅크 로봇 회사 인수, 오픈AI/AMD 뉴스 → 로봇+반도체 강세
- 원익홀딩스 상한가, 클로봇 상한가, 사명/로보티즈 20%+ 상승
- 반도체는 D+1 위치(매물 부담) vs 로봇은 첫날 급등(매물 부담 없음) → 로봇 집중
- 상따 관점으로 매수 → 1부 상한가 익절 → 눌림 반복 매매 → 남은 물량 오버나잇

### [03:00~05:30] 미장 폭락 후 D+1 대응
- 트럼프 중국 관세 100% → 나스닥 4%+ 하락 → 국내 시장 조정
- 주도 대장주 오버나잇 상태: 미장 폭락에도 두려울 필요 없음
- 갭상승 시 수익 실현, 낮게 시작 시 오히려 추가 매수 기회
- 장전 시간외(8:30~8:40) 전일 종가에 추가 매수 시도
- 2개 계좌 합산 약 2,670만원 수익

### [05:30~09:30] 테마 선택 기준 - 해지성 테마 회피
- 반도체: 시총 500조+300조 → 지수 영향 크게 받음 → 지수 약세일 날 회피
- 희토류 관련주: 지수와 반대로 움직이는 해지성 테마
- 해지성 테마 리스크: (1) 뉴스 바뀌면 급락 (2) 지수 반등 시 나 혼자 손실 → 매매 엇박

## 4. 핵심 매매 전략/교훈

1. **상따 매매: D+0 대장주 확인 → 1부 상한가 익절 → 나머지 오버나잇** - 강한 테마일 때만 실행
2. **미장 폭락에도 주도 대장주는 공포 금지** - 갭상승 시 익절, 낮게 시작 시 추매 기회
3. **장전 시간외(8:30~8:40) 추가 매수 활용** - 전일 종가 가격 매수 가능
4. **매물 부담 없는 첫날 급등 테마 집중** - D+1 위치 종목보다 우선
5. **해지성 테마는 가능하면 공략하지 않기** - 매매 엇박 → 심리 붕괴 위험

## 6. 명언/핵심 문장

> "정말 강한 테마가 등장했을 때 활용할 수 있는 상한가 따라잡기법 그대로 공략만 하셨더라면 오늘 시장은 미장이 급락했다고 하더라도 무서워할 필요가 없었던 시장이었습니다."

> "해지 테마를 매수했는데 지수가 크게 반등해서 나 혼자 손실을 보는 경우 수익 낼 기회까지 놓치면서 매매가 완전히 엇박을 탈 수 있습니다."

- [ ] 미장 폭락 시 주도 대장주 보유 중이면 공포 매도 금지
- [ ] 장전 시간외(8:30~8:40) 추가 매수 기회 활용
- [ ] 해지성 테마(희토류, 방어주 등)는 압도적 상황 아니면 회피
