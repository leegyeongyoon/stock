# 163. 주도테마 확실한 날은 '이렇게' 매매하세요

## 1. 영상 개요
반도체 테마가 확실히 주도하는 날의 실전 매매법을 설명하며, 한미반도체에서 가온칩스로 대장주가 교체되는 과정을 포착하고 전고점 돌파 장대양봉 패턴으로 월 2억1500만원 수익을 달성한 사례를 공유하는 영상.

- **채널**: 대왕개미 홍인기
- **업로드일**: 2024-03-28
- **영상 길이**: 8분 8초
- **조회수**: 7.7만
- **URL**: https://www.youtube.com/watch?v=k61f_paSRMI

## 3. 주요 내용 정리

### 주도테마 판별 (00:00~03:00)
- 거래대금 상위를 확인하여 반도체 테마가 시장을 주도하는 날 판별
- 여러 반도체 관련주가 동시에 상승하면 "확실한 주도테마"로 판단

### 대장주 교체 포착 (03:00~05:00)
- 한미반도체가 기존 대장주였으나 상승률이 둔화
- 가온칩스의 상승률이 더 높아지면서 대장주 교체 신호 발생
- 대장주 교체 시 새로운 대장주에 수급이 집중되는 패턴

### 전고점 돌파 장대양봉 공략 (05:00~08:00)
- 가온칩스가 전고점 돌파하며 장대양봉 발생 시 매수 진입
- 장대양봉 발생 당일(D+0) 매매로 높은 수익률 달성
- 월 수익 2억1500만원 공개

## 4. 핵심 매매 전략/교훈

1. **주도테마가 확실한 날에만 공격적 매매**: 애매한 날은 보수적으로
2. **대장주 교체 신호 포착**: 상승률 역전이 나타나면 즉시 새 대장주로 갈아타기
3. **전고점 돌파 + 장대양봉 = 최고의 매수 타점**: 이 패턴에서 확률이 가장 높음
4. **확실한 날에 집중 매매**: 매일 매매하지 않고, 확실한 기회에 비중 배팅
