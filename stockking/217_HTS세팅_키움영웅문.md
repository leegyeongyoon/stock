## 3. 주요 내용 정리

- **[00:00~01:12]** 거래대금 상위 (0186)
  - 종목 찾기의 핵심 화면
  - 돈이 몰리는 종목 확인 -> 테마 파악 -> 상승률 높은 종목 = 주도 테마 대장주
  - 코스피/코스닥 전체 보기, ETF/ETN 제외

- **[01:12~02:04]** 상승률 상위 (0181)
  - 아침 일찍 상한가 들어가 거래대금 적은데 높은 상승률인 대장주 체크용
  - 미니 버튼으로 간소화

- **[02:04~03:08]** 관심종목 (0130) - D+0/D+1/D+2 시스템
  - 거래대금 동반 장대양봉 종목 -> D+0에 넣기
  - 하루씩 D+1, D+2로 이동 -> 장대양봉 나온 종목 이틀 공략
  - 항상 인기 종목도 별도 관리

- **[03:08~04:10]** 현재가창 2개 운용 (0011)
  - 1번: 매매 대상 대장주
  - 2번: 같은 테마 2등주 (테마 흐름 확인용)
  - 호가창, 거래원, 체결, 시총, 유통주식, VI 발동 예상가 확인

- **[04:10~04:54]** 미니체결창 (0120)
  - 1천만 원 이상 거래는 별도 표시
  - 1억 이상 체결은 노란색 강조
  - 큰 물량 유입 확인용

- **[04:54~05:24]** 주문창 (8949) - 금액 기반 주문
  - 주식수가 아닌 금액으로 설정 -> 비중 관리 수월
  - 예: 1억 매수 시 3,300만 원씩 3번 분할

- **[05:24~06:07]** 잔고창 (0345) + 미체결창 (0341)
  - 수익/손실 가리기: 미체결창으로 손익 부분 가림
  - 수익률과 평가금액만 표시
  - 미체결창: 취소 주문 버튼으로 빠른 주문 취소

- **[06:07~07:00]** 차트 활용 (0600)
  - 일봉 + 분봉 동시 표시
  - 일봉: 큰 방향성 판단
  - 분봉: 매매 타이밍 판단
  - 단타라도 분봉만 보면 큰 방향성 놓침

- **[07:00~07:54]** 프로그램 매매 (0778) + 투자자별 매매 (1051)
  - 0778: 외국인 실시간 매매 확인 (참고용, 맹신 금지)
  - 1051: 기관 가집계 (2차~5차 시간에 유효)
  - 큰 방향성 참고용으로만 활용

- **[08:07~09:40]** 지수 분석 창
  - 코스닥 지수 분봉 (0212): 선 차트로 당일 흐름
  - 코스닥 일봉 (0620): 20일선 위=종목 상승 힘 강 -> 오버나잇 적극
  - 코스피 200 선물 1분봉 (0630): 시장 변동성 가장 빠르게 반응

## 4. 핵심 매매 전략

1. **거래대금 상위로 주도 테마 발굴**: 돈이 몰리는 곳에서 대장주 선정
2. **D+0/D+1/D+2 관심종목 관리**: 장대양봉 종목 이틀간 공략
3. **현재가창 2개 (대장주+2등주)**: 테마 전체 흐름 동시 확인
4. **금액 기반 분할 매수**: 주식수 아닌 금액으로 비중 관리
5. **일봉(방향성) + 분봉(타이밍)**: 단타라도 일봉 큰 방향 먼저 확인
6. **코스닥 20일선 기준 오버나잇**: 위=적극, 아래=보수적
7. **외국인/기관 수급은 참고만**: 맹신하면 뇌동 매매 유발

## 6. 명언 / 인사이트

> "단타를 한다고 해서 분봉만 보고 매매하면 큰 방향성을 놓치는 경우가 있어서 일봉과 분봉을 동시에 띄워놓고 매매하고 있습니다."

> "실시간으로 손익이 움직이는 걸 보면 마음이 흔들려서 매매하는 데 방해가 됩니다."

> "외국인이 산다고 바로 사고 판다고 바로 파는 것이 아니라 큰 방향성을 보고 참고하는 정도로만 사용해야 합니다."
