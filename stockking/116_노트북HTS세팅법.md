노트북 한 대로 키움증권 영웅문 HTS를 효율적으로 세팅하는 방법을 설명하는 영상. 홍인기 트레이더가 직접 PD 노트북에서 매매용 화면과 종목 선정용 화면을 나눠서 세팅하는 실전 과정을 보여준다.

## 3. 주요 내용 정리

### [00:00~01:00] 도입 - 노트북 매매 필요성
- 홍인기는 메인으로 43인치 모니터 사용
- 직장인/학생은 노트북으로 매매하는 경우가 많음
- 키움증권 영웅문 기준으로 설명

### [01:00~03:10] 기본 화면 정리 및 핵심 창 배치
- HTS 하단/옆 불필요한 툴바 모두 제거 (쾌속주문, 종목, 차트, 티커, 화면 툴바)
- **키움 현재가 창** (화면번호 0010) - 현재가, 거래원, 주문체결 정보
- **미니 주문창** - 호가 주문보다 편리
- **종합 차트 창** (화면번호 0600) - 일봉/분봉 돌려가며 확인
- 모든 창 타이틀 바 제거하여 화면 최대 확보

### [03:50~05:45] 보조 정보 창 추가
- **관심 종목 창** (0100번) - 당일 시장 주도 장대양봉 종목 관찰
- **프로그램 매매 창** (07784) - 외국인 수급 실시간 확인
- **종목별 투자자별 매매 추이** (1051) - 기관 수급 확인
- **실시간 잔고** (0345) - 보유 종목 확인
- **실시간 미체결** (0341) - 미체결 주문 관리

### [05:45~07:10] 시장 지수 모니터링
- **시장 당일 등락률 차트** (0641) - 코스닥 지수 실시간 확인
- **선물옵션 미니 차트** (0630) - 코스피200 선물 1분봉으로 시장 흐름 빠르게 체크
- 단기 매매 종목은 코스닥 지수 움직임과 연관이 많음

### [07:10~08:10] 1번 가상 화면 최종 배치
- "화면 크기 확장 시 글자 크기 고정하기" 설정 필수 (기능 > 종합환경설정 > 기타환경)
- 차트 크기 최소화하여 많은 창 배치

### [08:30~10:30] 2번 가상 화면 세팅 (종목 선정용)
- **거래대금 상위 창** - 종목 발굴 핵심 도구
- **전일 대비 등락률 상위** (0181) - 상한가 종목 등 확인
- **일봉 차트 + 분봉 차트** 동시 배치

### [10:30~12:50] 실전 매매 워크플로우
- 2번 화면에서 거래대금 상위로 종목 선정 후 관심종목에 등록
- 1번 화면으로 전환하여 실제 트레이딩 진행
- 대장주뿐 아니라 2등주, 3등주, 다른 테마 흐름도 실시간 확인 필요

## 4. 핵심 매매 전략

- **2화면 분리 전략**: 1번 화면은 트레이딩 전용, 2번 화면은 종목 선정 전용
- **거래대금 상위 중심**: 종목 발굴의 기본 도구로 거래대금 상위를 활용
- **관심종목 활용**: 테마 대장주와 2등주, 3등주를 관심종목에 넣고 실시간 모니터링
- **수급 실시간 확인**: 외국인(프로그램 매매)과 기관 수급을 장중에 계속 체크
- **지수 연동 파악**: 코스닥 지수와 코스피200 선물로 시장 흐름 빠르게 판단

## 5. 종목 / 섹터 분석

| 종목/섹터 | 언급 맥락 | 비고 |
|-----------|-----------|------|
| LS 에코 에너지 | 거래대금 상위 예시 종목 | 실제 매매 예시로 활용 |
| 코스닥 지수 | 단기 매매 종목과 연관성 높음 | 실시간 모니터링 필수 |
| 코스피200 선물 | 시장 흐름 가장 빠르게 확인 | 1분봉 기준 |

## 6. 명언 / 핵심 발언

> "노트북으로 볼 때는 한 화면에 매매에 필요한 정보를 모두 넣기는 어려워서 첫 번째 화면은 트레이딩 하는데 필요한 화면을, 두 번째 화면은 종목 선정을 할 때 필요한 화면을 설정해 놨습니다."

> "매매를 할 때 대장주 한 종목의 흐름만 보고 판단을 할 게 아니라 같은 테마의 2등주, 3등주나 또 다른 테마 종목의 흐름이 어떤지도 실시간으로 확인을 해 줘야지 판단이 됩니다."

## 7. 체크리스트

- [ ] 키움증권 영웅문 불필요한 툴바 모두 제거했는가
- [ ] 타이틀 바 제거로 화면 공간 최대 확보했는가
- [ ] "화면 크기 확장 시 글자 크기 고정하기" 설정했는가
- [ ] 1번 가상화면에 트레이딩 필수 창 배치 완료했는가 (현재가, 주문, 차트, 관심종목, 잔고, 미체결, 수급)
- [ ] 2번 가상화면에 종목 선정 창 배치 완료했는가 (거래대금 상위, 등락률 상위, 일봉/분봉 차트)
- [ ] 코스닥 지수와 코스피200 선물 차트 모니터링 창 설정했는가
- [ ] 프로그램 매매(외국인 수급)와 기관 수급 확인 창 추가했는가
