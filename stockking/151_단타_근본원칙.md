## 3. 주요 내용 정리

### [00:00~02:10] 햄버거 이론 (거래대금의 힘)
- '햄버거' = 종목이 상승하기 위해 필요한 거래대금의 힘을 비유
- 10개 먹어야 힘 쓸 수 있는 종목이 8개만 먹으면 매매하지 않음
- 20개 먹으면 상한가까지 볼 수 있는 기대치 상향
- **매매 판단 1순위로 거래대금(햄버거) 확인**

### [02:10~06:20] 교집합 매매의 중요성
- 예전에는 한 가지만 봐도 수익 가능했으나 지금은 불가능
- **3가지 이상 조건의 교집합이 나와야 매매 확률 상승**
- 프로그램 매매가 매도 중일 때 대형주는 조심, 중소형주는 상황에 따라 가능
- 뉴스 발생 후 프로그램 매도를 리셋해서 다시 판단해야 함

### [06:20~09:20] 중소형주 대장주 매매법
- 중소형주가 대장주일 때는 같은 테마의 중대형주 흐름을 참고
- 중대형주 거래대금이 상위 12위 안에 들면 테마 지속 신호
- 중대형주가 무너지면 중소형주도 정리

### [09:20~12:00] 분할매수 vs 일괄매수
- 갈 주식은 한 번 사면 바로 감 - 2차/3차 매수가 필요하면 이미 잘못된 것
- 확신 있을 때는 빠르게 여러 번 클릭해서 비중 높이기
- 시간 분할 매수보다 확신에 따른 비중 조절이 중요

### [12:00~16:00] 큰 손실 후 멘탈 관리
- 큰 손실 후 복구 심리가 추가 손실을 부름
- 현실적 방법: 심호흡 + 10분간 화면에서 떨어지기
- 손실의 흐름을 끊는 것이 핵심 (메꾸려는 생각 버리기)
- 장대음봉(큰 손실)을 막기 위한 개인별 방지책 만들기

### [16:00~19:33] 손절 후 재진입과 시황 판단
- **한 종목 최대 3번 손절하면 상종 안 함** (불개미 원칙)
- 아침 게임비(1,000만 원) 각오하고 매매 시작
- 시황/재료만 보고 선치매하지 말고 거래대금 확인 후 진입
- 단타는 시장 반응 나올 때 매매하는 것이 원칙

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 햄버거(거래대금) 우선 | 매매 판단 1순위로 거래대금의 힘 확인 |
| 교집합 매매 | 3가지 이상 조건(수급, 일봉, 거래대금 등) 교집합 시 매매 |
| 한 종목 3번 손절 규칙 | 같은 종목 3번 손절하면 더 이상 진입하지 않음 |
| 손실 흐름 끊기 | 큰 손실 후 복구 심리 대신 손실 흐름 차단에 집중 |
| 확신 비례 비중 | 확신 강하면 빠르게 비중 높이고, 약하면 소비중 |
| 시장 반응 후 진입 | 재료/시황만으로 선치매하지 않고 시장 반응 확인 후 매매 |
