## 3. 주요 내용 정리

**[00:43~02:18] 계좌 전환의 핵심 = 손실 줄이기**
- 매매 기법 정립도 중요하지만, 계좌 성장의 진짜 열쇠는 손실을 줄이는 것
- 대부분 수익 늘리는 데만 집중하지만, 손실 줄여서 계좌 수익을 높이는 것이 훨씬 쉬움
- 예: 한 달 수익 1억 / 손실 1억 1천만원 -> 천만원 손실
- 1억 수익을 더 늘리려 하기보다 1억 1천만원 손실을 줄이는 것이 효과적

**[02:18~04:25] 반복되는 손실 패턴 분석**
- 사람 심리상 손실은 잊어버리려 하고, 수익만 기억하려 함
- 손실 원인을 잊지 말고 분석하는 것이 전환의 시작
- 홍인기의 반복 실수 2가지:
  1. 떨어지는 종목 추가 매수(물타기) -> 반등 없이 계속 하락 -> 한번에 큰 손실
  2. 장중 매매 손실 후 손절 못하고 강제 오버나잇 -> 다음날 갭하락 -> 더 큰 손실

**[04:25~05:48] 오답노트 작성 + 매일 읽기**
- 매매일지에 수익이 아닌 큰 손실 발생 시 실수 내용과 이유를 오답노트처럼 기록
- 컴퓨터 앞에 두고 매일 장 시작 전 한 번씩 읽음
- 같은 실수를 반복하지 않기 위해 의식적으로 노력
- 결과: 특별히 수익을 더 내지 않았음에도 큰 손실 감소 -> 계좌 수익 크게 향상

**[05:48~06:50] 손실 감소의 선순환**
- 큰 손실 줄어듦 -> 뇌동매매 감소 -> 차분한 매매 가능 -> 수익 상황 증가
- 심리 안정이 매매 실력 향상으로 이어지는 선순환 구조

**[06:50~07:05] 실천 당부**
- 과거 매매 내역 복기 -> 큰 손실 원인 정리 -> 오답노트 작성 -> 매일 읽기
- 같은 실수를 반복하지 않으면 계좌에 큰 변화가 있을 것

## 6. 명언 / 핵심 문장

> "어떻게 하면 수익을 낼 수 있을지 고민하는 것도 중요하겠지만 제가 생각하기에는 그거보다 훨씬 더 중요한 건 큰 손실을 줄이는 것입니다."

> "수익을 늘리는 것보다 손실을 줄여서 계좌 수익을 늘리는게 훨씬 더 쉽습니다."

> "큰 손실이 날 때마다 내가 어떤 실수를 해서 어떤 이유로 손실을 받는지 오답 노트처럼 적어 뒀고 그것을 컴퓨터 앞에 두면서 매일 장 시작하기 전마다 한 번씩 읽어봤습니다."

> "큰 손실을 많이 줄이다 보면 뇌동 매매도 줄어들고 훨씬 차분하게 매매를 할 수 있게 되면서 수익을 내는 상황도 크게 많아졌습니다."

## 7. 체크리스트

- [ ] 과거 매매 내역에서 큰 손실이 발생한 원인을 분석했는가
- [ ] 반복되는 손실 패턴을 파악했는가 (물타기, 강제 오버나잇 등)
- [ ] 오답노트를 작성하여 손실 원인을 기록하고 있는가
- [ ] 매일 장 시작 전 오답노트를 읽고 있는가
- [ ] 수익 늘리기보다 손실 줄이기에 더 집중하고 있는가
- [ ] 떨어지는 종목에 물타기를 하고 있지 않은가
- [ ] 장중 손절 못한 종목을 억지로 오버나잇하지 않는가
- [ ] 심리가 안정된 상태에서 매매하고 있는가
