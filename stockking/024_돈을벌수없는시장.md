## 3. 주요 내용 정리

### 현재 시장 상황 (00:00~02:00)
- 시프트업에서 약 4,000만원 손실 발생 (신규상장 첫날 매매)
- 두산로보틱스에서도 손실 발생
- 코스닥 지수가 20일 이동평균선 아래에 위치한 약세장
- 거래대금이 줄어들어 매매하기 어려운 환경

### 하락장에서의 대응 전략 (02:00~04:30)
- **매매 횟수를 줄여야 함** - 장이 안 좋을 때 많이 매매하면 손실 누적
- **비중을 줄여야 함** - 평소 대비 절반 이하로 운영
- 시장이 안 좋을 때는 거래대금이 빠지면서 변동성만 커짐
- 장이 좋을 때 번 돈을 하락장에서 지키는 것이 핵심

### 절대 하지 말아야 할 것들 (04:30~06:30)
- **기법을 바꾸지 말 것** - 잃는다고 새로운 방법을 찾으면 더 잃음
- **추가 입금 절대 금지** - 손실을 만회하려 돈을 넣으면 더 큰 손실로 이어짐
- 하락장에서 수익을 내려 무리하지 말 것
- 시장 탓이지 본인 실력 탓이 아님을 인지할 것

### 회복 시그널 판단법 (06:30~08:12)
- **코스닥 지수가 20일선 위로 올라올 때** 공격적 매매 재개
- **거래대금 10조원 이상이 며칠간 유지**될 때 시장 회복 신호
- 지수와 거래대금 두 가지 조건이 동시에 충족되어야 함
- 그때까지는 인내심을 가지고 기다릴 것

## 4. 핵심 매매 전략/교훈

### 전략 1: 하락장 생존 법칙
- 코스닥 20일선 아래 = 약세장 → 매매 횟수와 비중 모두 축소
- 수익 목표를 낮추고 원금 보존에 집중
- "돈을 벌겠다"는 생각보다 "안 잃겠다"는 마인드가 중요

### 전략 2: 회복 타이밍 포착
- 코스닥 지수 20일선 돌파 + 거래대금 10조 이상 지속 = 공격 재개 시그널
- 두 조건이 동시에 맞아야 하며, 하나만으로는 부족

### 전략 3: 심리 관리
- 하락장에서 기법 변경 = 최악의 선택 (기존에 검증된 기법 유지)
- 추가 입금으로 손실 만회 시도 = 더 큰 재앙의 시작
- 시장이 나쁜 것이지 본인 탓이 아니라는 점 인식
