# 108. 오르는 주식은 '이 패턴'을 가지고 있습니다

## 1. 영상 개요

## 2. 핵심 키워드
`#강세패턴` `#끼있는종목` `#테마지속성` `#신고가` `#대형주단타` `#HLB` `#한미반도체` `#시총10조` `#2차전지` `#AI반도체`

## 3. 주요 내용 정리

### [00:00~03:00] 대형주만 오를 때 대응법
- 시총 10조 넘는 종목은 보통 변동성 부족 → 단타 부적합
- 대형주만 오르고 테마 안 보이는 날 = 매매 쉬기
- 끼가 좋은 대형주는 예외 (HLB, 한미반도체 등)

### [03:00~07:00] 끼 있는 종목 판별법
- 일봉 차트에서 강세 패턴(시초가 대비 종가 10%+) 빈도 확인
- 최근 크게 상승한 이력 있는 종목 = 끼 있음
- 일봉상 너무 많이 오른 종목(상한가+10%+) = 회피
- 횡보 없이 단기간 2배+ 상승 종목도 회피

### [07:00~13:00] 오래 지속되는 테마의 특징
- 일시적 뉴스가 아닌 산업 전체 기대감 → 장기 상승 (에코프로/2차전지)
- 테마 내 종목들이 신고가 근처에 다수 있을 때 = 테마 지속 신호
- 대부분 신고가에서 이탈한 종목이 많으면 = 테마 약화 신호

## 4. 핵심 매매 전략/교훈

1. **끼 있는 종목 = 일봉에 강세 패턴 빈도 높은 종목** - 차트 역사 확인 필수
2. **테마 지속성 판단: 신고가 종목 다수 = 지속** - 이탈 종목 다수 = 종료
3. **시총 10조+ 대형주도 끼 있으면 단타 가능** - HLB, 한미반도체 예시
4. **너무 올랐다고 느끼면 진입하지 말 것** - 심리적 부담 = 흔들림
5. **산업 전체 기대감 테마가 가장 오래 감** - 개별 이슈보다 우선

## 5. 주요 종목/섹터 언급

| 종목/섹터 | 맥락 |
|-----------|------|
| HLB | 시총 15조, 끼 있는 대형주 예시 |
| 한미반도체 | 시총 10조+, 강세 패턴 예시 |
| 에코프로 | 장기 상승 테마(2차전지) 예시 |
| AI 반도체 | 장기 기대감 테마 예시 |
| 삼성전자/하이닉스 | 끼 없는 대형주 예시 |

> "본인이 너무 높다고 생각하면 안 들어가는게 좋습니다. 심리적인 면에서 접근을 안 하는 것을 추천드리고 싶습니다."

- [ ] 매매 대상 종목의 일봉에서 강세 패턴 빈도 확인 (과거 6개월~1년)
- [ ] 시총 10조+ 종목은 끼가 확인된 경우에만 진입
- [ ] 테마 내 신고가 종목 비율로 테마 지속성 판단
