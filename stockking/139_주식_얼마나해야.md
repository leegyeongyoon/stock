# 139. 주식을 잘하려면 얼마나 해야할까

## 3. 주요 내용 정리

### [00:00~01:09] 주식 경력 소개
- 2010년 중학교 2학년 때 주식 시작, 14년차
- 단타는 2017년부터 시작 (바이오주, 대북주 시기)
- 2020년 전역 후 본격적으로 하루 종일 매매, 단기 매매 4~5년차

### [01:09~02:34] 단타 숙련에 필요한 시간
- 꾸준히 수익 내려면 약 **3년** 집중 필요
- 다른 직업(학교 16년+) 대비 3년은 짧은 편
- 다만 모든 사람이 3년 만에 성공하긴 어려움

### [02:34~03:16] 시행착오의 중요성
- 깡통 경험 후 잘못된 것을 고쳐나가는 과정 필수
- **올바른 방법**을 배우는 것이 핵심 (잘못된 방법 → 시간 낭비 + 복구 시간 추가)

### [03:19~05:00] 단타에 필요한 3가지 자질
1. **감정 기복이 적은 것** - 수익/손실에 흔들리면 이성적 판단 불가
2. **빠른 판단력과 순발력** - 매수/손절 타이밍을 주저 없이 실행
3. **숫자 감각** - 거래대금, 호가창 물량, 거래량 실시간 파악

### [05:00~07:02] 가장 중요한 것: 주식을 좋아하는 마음
- 주식을 **즐길 수 있어야** 장기적 성공 가능
- 100억 받고 주식 못하기 vs 계속하기 → 주식 계속하기 선택
- 좋아하는 일이어야 시간 투자 대비 효율이 높음

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 3년 집중 투자 | 단기 매매로 꾸준한 수익을 내려면 최소 3년간 집중해야 함 |
| 올바른 방법 학습 | 잘못된 방법을 배우면 시간 낭비 + 교정 시간 추가 소요 |
| 감정 컨트롤 | 수익/손실에 따른 감정 기복을 최소화해야 이성적 판단 가능 |
| 빠른 실행력 | 매수/매도 판단이 맞다면 주저 없이 실행하는 능력 필요 |
| 즐기는 마인드 | 주식을 돈벌이 수단이 아닌 좋아하는 일로 접근해야 지속 가능 |
