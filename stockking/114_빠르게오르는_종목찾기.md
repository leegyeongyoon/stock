# 114. 빠르게 오르는 종목 찾는 방법

## 1. 영상 개요
- **한줄 요약:** 시장보다 강한 주도 테마 대장주의 장대양봉 패턴이 시장 반등 시 가장 먼저 상승하는 원리와 실전 예시
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2024-11-15
- **영상 길이:** 8분 32초
- **원본 URL:** https://www.youtube.com/watch?v=HGAg-NnQVaU

## 2. 핵심 키워드
`#시장보다강한종목` `#장대양봉` `#반등선도주` `#한화오션` `#현대중공업` `#알테오젠` `#한화시스템` `#펩트론` `#삼성전자` `#2차전지소외`

## 3. 주요 내용 정리

### [00:00~03:00] 삼성전자 반등과 시장보다 강한 종목
- 삼성전자 5만원 근처 도달 후 7% 반등, 10조원 자사주 매입 공시
- 시장 낙폭 과대 상황에서 주도 테마 대장주를 매수하면 가장 빠르게 반등
- 조선 테마: 한화오션이 장대양봉 발생 후 지수 하락에도 상대적 강세

### [03:00~06:00] 강한 테마 대장주의 반등 패턴
- 한화오션: 장대양봉 → 지수 3일 하락에도 강세 유지 → 시장 반등 시 즉시 장대양봉
- 현대중공업: 같은 패턴으로 반등 선도
- 방산 테마: 한화시스템 거래대금 동반 장대양봉 → 지수 하락 무시 → 반등 시 급등
- 바이오 테마: 알테오젠/펩트론 신고가 돌파 장대양봉 → 시장 반등 시 가장 먼저 상승

### [06:00~08:30] 약한 종목의 반대 예시
- 2차전지(에코프로BM): 시장보다 먼저 하락 + 시장 반등해도 계속 하락
- 초보자 실수: 많이 떨어진 종목 = 싸다 → 매수 → 큰 손실
- 삼성전자도 코스피 대비 선행 하락 → 시장보다 약한 종목은 회피

## 4. 핵심 매매 전략/교훈

1. **시장보다 강한 종목 = 거래대금 동반 장대양봉 발생 종목** - 이 종목이 반등 선도
2. **시장 하락에도 버티는 종목이 진짜 주도주** - 지수 하락 시 상대적 강세 확인
3. **많이 떨어진 종목 매수는 큰 실수** - 싸 보이는 종목 = 소외된 종목
4. **코스피 지수와 개별 종목 차트 비교** - 지수 대비 강한지 약한지 판단
5. **주도 테마 복수 확인** - 조선/방산/바이오 등 여러 강한 테마에서 동시 패턴 확인

## 6. 명언/핵심 문장

> "종목을 선정할 때는 시장보다 강한 종목을 선정해야 됩니다. 거래대금을 동반한 장대양봉이 발생했던 종목을 공략하면 시장이 반등 시도를 할 때 가장 먼저 반등합니다."

> "초보자분들은 많이 떨어진 종목이 싸니까 올라가겠지라는 생각에 매수하시면 정말 큰일납니다."

## 7. 실전 적용 체크리스트

- [ ] 시장 하락 시 거래대금 동반 장대양봉 나온 종목 리스트 작성
- [ ] 지수 하락에도 상대적으로 버티는 종목 = 반등 선도 후보
- [ ] 코스피 지수와 개별 종목 일봉 비교하여 강약 판단
- [ ] 많이 떨어진 종목(2차전지 등)은 단타 대상에서 제외
- [ ] 여러 주도 테마(조선/방산/바이오)에서 동일 패턴 발생 시 테마 강도 확인
