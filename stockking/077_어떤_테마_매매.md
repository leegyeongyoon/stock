# 077. 어떤 테마를 매매해야할까

## 3. 주요 내용 정리

### [00:00~02:00] 지수 및 시장 분위기
- 코스피/코스닥 모두 20일선 위 유지 중
- 거래대금도 양호한 수준
- 매매하기 비교적 좋은 시장 환경

### [02:00~04:00] 주요 테마 분석
- **방산 테마**: 인도-파키스탄 갈등 격화로 방산주 강세, 현대로템 신고가
- **화장품 테마**: APR(에이프릴스킨) 중심 화장품주 강세
- **정치 테마주**: 이재명 관련 테마주 움직임

### [04:00~04:59] 테마 선정 기준
- 가장 강한 테마에 집중 (거래대금 상위 테마)
- 여러 테마에 분산하지 말고 압도적인 주도 테마 1~2개에 집중
- 주도 테마 내에서 대장주를 매매

---

## 4. 핵심 매매 전략/교훈

1. **가장 강한 테마에 집중**: 여러 테마가 동시에 나올 때 가장 압도적인 1~2개에만 집중
2. **코스피/코스닥 20일선 확인**: 두 지수 모두 20일선 위면 적극 매매 가능
3. **대장주 신고가 매매**: 현대로템처럼 신고가를 돌파하는 종목이 가장 매매하기 수월
4. **정치 테마주 주의**: 변동성이 크므로 확신 있을 때만 소량 접근

| 종목/섹터 | 맥락 |
|-----------|------|
| 현대로템 | 방산 대장주, 신고가 돌파 |
| 방산 테마 전반 | 인도-파키스탄 갈등으로 강세 |
| APR(에이프릴스킨) | 화장품 테마 대장주 |
| 이재명 정치 테마주 | 정치 이벤트 관련 변동성 |

## 7. 실전 적용 체크리스트

- [ ] 코스피, 코스닥 지수 모두 20일선 위인지 매일 확인하기
- [ ] 당일 거래대금 상위에서 가장 많은 종목이 포함된 테마를 주도 테마로 선정하기
- [ ] 주도 테마 내 신고가 돌파 종목을 대장주로 매매하기
- [ ] 정치 테마주 매매 시 소량 비중으로 접근하기
- [ ] 2개 이상 테마에 분산 투자하지 않기
