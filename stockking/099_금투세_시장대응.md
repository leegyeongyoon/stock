# 099. 금투세 시장 충격 이렇게 대응하세요

## 1. 영상 개요
- **한줄 요약:** 금융투자소득세 이슈로 거래대금 급감한 시장에서의 보수적 매매 전략과 대응법
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2024-04-11
- **영상 길이:** 7분 36초

## 2. 핵심 키워드
`#금투세` `#거래대금급감` `#코스닥지수` `#20일선` `#하락장대응` `#비중축소` `#매매횟수줄이기` `#손실방어` `#시장상황판단`

## 3. 주요 내용 정리

### [00:00~03:00] 시장 상황 분석
- 코스닥 지수 4월부터 하락, 20일선 이탈
- 코스닥 거래대금 6조 4천억 → 최근 10조+ 대비 급감
- 금투세 이슈가 거래대금 감소의 주요 원인
- 코스닥 지수 20일선 위 = 상승추세 → 매매 유리 / 아래 = 하락추세 → 매매 불리

### [03:00~05:00] 실전 매매 복기
- 솔루스첨단소재: 전일 상한가 → 갭상승 후 눌림매매 → 지지선 무너져 -4% 손절
- 한미반도체: 전고점 근처 매수 → 예상대로 안 가서 -2% 손절
- 이수페타시스: 오후 진입 → 거래대금 급감 확인 → 매수가 근처 매도
- 당일 약 2천만원 손실, 그러나 4월 전체 약 1억 수익

### [05:00~07:00] 하락장 대응 전략
- 거래대금 줄면 매매 금액과 횟수 축소
- 수익을 많이 내려는 생각 버리고, 이전 수익 지키기에 집중
- 시장은 반드시 좋아지므로 너무 걱정할 필요 없음
- 예상하지 말고 시장 상황에 맞게 대응만 하면 됨

## 4. 핵심 매매 전략/교훈

1. **코스닥 지수 20일선 위/아래 확인** - 상승추세 vs 하락추세 판단
2. **거래대금 급감 시 매매 금액/횟수 축소** - 보수적 매매로 전환
3. **좋은 장에서 번 돈 지키기** - 안 좋은 장에서 수익 반납 방지
4. **시장 예측하지 말고 대응하라** - 금투세 영향 예상해봤자 소용없음
5. **테마 없는 날은 쉬는 것이 정답** - 억지로 매매하지 말 것

## 5. 주요 종목/섹터 언급

| 종목/섹터 | 맥락 |
|-----------|------|
| 솔루스첨단소재 | 전일 상한가 → 눌림매매 실패 |
| 한미반도체 | 전고점 돌파 기대 → 실패 |
| 이수페타시스 | 반도체 테마 → 거래대금 급감으로 정리 |
| 코스닥 지수 | 20일선 이탈 = 하락추세 |

## 6. 명언/핵심 문장

> "이런 상황 속에서는 수익을 많이 내려는 생각보다는 이전 좋은 장에 벌어 왔던 거 지키고 일단 손실을 보지 않는다는 생각으로 버텨 나가야 된다는 생각으로 매매를 해야 됩니다."

> "앞으로 시장이 금융투자소득세 때문에 안 좋다고 예상을 해봤자 내가 예상하는 대로 움직이는 것도 아니고 그냥 있는 그대로 시장 상황에 맞게 대응하면서 매매하시면 될 거 같습니다."

## 7. 실전 적용 체크리스트

- [ ] 코스닥 지수가 20일선 위/아래인지 매일 확인
- [ ] 코스닥 거래대금이 최근 평균 대비 급감했는지 체크
- [ ] 거래대금 급감 시 매매 금액 50% 이상 축소
- [ ] 하락장에서는 이전 수익 지키기에 집중
- [ ] 테마가 없는 날은 매매하지 않기
