## 3. 주요 내용 정리

**[00:00~00:47] 레인보우 로보틱스 장중 변동성 리뷰**
- 삼성전자 3자배정 유상증자 뉴스로 거의 상한가 도달
- 시초가 +15% -> 상한가 접근 -> 쌍봉 후 +9%까지 하락 -> 오후 재반등 -> 상한가 근처 마감
- 하루 중 극심한 변동성을 보여준 사례

**[00:47~01:28] 기관투자자 가집계의 영향 (핵심)**
- 키움증권 화면번호 1051번: 종목별 투전사별 매매 추이(잠정)
- 09:49 가집계: 보험, 투신, 연기금, 기타법인 모두 매도 -> 주가 급락
- 11:03 가집계: 기관투자자 여전히 전부 매도 -> 상한가 근처에서 +9%까지 하락
- 13:11 가집계: 투신이 갑자기 8만 8천주 대량 매수로 전환 -> 12시부터 반등 시작 -> 상한가 근처까지 재상승

**[01:39~02:04] 프로그램 매매 vs 기관투자자 가집계**
- 과거에는 외국인 투자자 동향인 프로그램 매매의 영향이 매우 컸음
- 프로그램 매매는 방송/유튜브에서 너무 많이 언급 -> 거의 모든 개인투자자가 확인
- 모두가 아는 정보가 되면서 프로그램 매매의 영향력이 줄어듦
- 대신 기관투자자 가집계의 영향이 크게 증가

**[02:04~03:18] 실전 매매 내역 공개**
- 오전: 레인보우 로보틱스 매매 중 소폭 수익
- 09:49 가집계 확인 -> 기관 전부 매도 -> 즉시 손절 (약 -3%, 200만원 손실)
- 손절 후 추가 10% 이상 하락 -> 손절 판단 정확
- 오후: 투신 대량 매수 전환 확인 -> 눌림목마다 적극 매수 -> 300만원 이상 수익
- 결과: 오전 -200만원 + 오후 +300만원 = 순수익 +100만원 이상

**[03:30~03:42] 레인보우 로보틱스 향후 전망**
- 장기간 횡보하다가 거래량 동반 장대양봉으로 저항선 돌파
- 다음 장에서도 눌림목 공략 가능한 차트 형태

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 기관 가집계 확인 | HTS 1051번 화면으로 장중 기관투자자 매수/매도 동향 실시간 체크 |
| 가집계 매도 시 즉시 손절 | 기관 전체가 매도 전환하면 보유 중이더라도 즉시 손절 |
| 가집계 매수 전환 시 재진입 | 기관(투신)이 대량 매수로 전환하면 눌림목에서 적극 매수 |
| 프로그램 매매 이상의 정보 | 모두가 아는 프로그램 매매보다 기관 가집계가 더 유효한 신호 |
| 손절 후 재진입 허용 | 손절했더라도 새로운 수급 신호가 나오면 같은 종목 재매수 가능 |
