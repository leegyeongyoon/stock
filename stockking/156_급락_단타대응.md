# 156. 주식시장 급락 단타 대응방법

## 1. 영상 개요
- **한줄 요약:** 코스닥 4% 하락, 코스피 3% 하락 등 시장 급락기에 단타 매매자가 어떻게 대응하는지 - 거래대금 축소, 잡주 횡행, 보수적 매매 전략을 실제 매매 사례와 함께 설명
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2024-08-04
- **영상 길이:** 14분 57초
- **원본 URL:** https://www.youtube.com/watch?v=QVz686hj0eM

## 2. 핵심 키워드
`#급락대응` `#거래대금축소` `#보수적매매` `#대왕고래` `#한선엔지니어링` `#상따매매` `#잡주회피` `#코스닥거래대금` `#테마매매` `#비매매전략`

## 3. 주요 내용 정리

### [00:00~03:00] 시장 상황 분석
- 코스닥 거래대금 6조 수준으로 급감
- 지수 지속 하락 → 매매 금액 줄이고 보수적 접근
- 6월 중순부터 지저분한 종목 다수 출현 → 대손실 유발

### [03:00~05:30] 거래대금 축소의 악순환
- 손실 → 거래대금 축소 → 테마 미형성 → 잡주만 상승
- 잡주는 유통금액 작아 예측 어려움 → 접근 어려움 → 거래대금 추가 감소
- 이 악순환이 계속 반복되는 구간

### [05:30~09:00] 실전 매매 사례 (대왕고래 테마)
- 월요일: 대왕고래 관련 한선엔지니어링 대장주로 상승
- 아람코와 애니의 대왕고래 프로젝트 참여 뉴스
- 상한가까지 상승 → 화요일 5% 갭상승 후 수익 실현
- 오랜만에 테마가 나와서 상따 관점 매매

### [09:00~15:00] 하락장 대응 원칙
- **매매 금액 줄이기** = 가장 중요한 전략
- 거래대금 없는 종목은 매매 안 함
- 기준에 맞는 종목이 없으면 매매를 하지 않는 것이 최선
- 1,100만 원 수익이라도 하락장에서는 충분히 좋은 성과

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 매매 금액 축소 | 시장 악화 시 매매 금액 대폭 축소 |
| 보수적 접근 | 기준에 맞지 않으면 매매하지 않기 |
| 잡주 회피 | 유통금액 작은 잡주는 예측 어려워 매매 자제 |
| 테마 출현 시 집중 | 오랜만에 테마 나오면 대장주에 집중 매매 |
| 비매매 = 수익 보존 | 하락장에서 매매 안 하는 것도 수익 |

## 6. 명언/핵심 문장

> "거래대금이 줄어서 테마도 나오지 않고 올라가는 종목도 잡주 위주로 올라가고 이런 악순환이 계속 반복되고 있습니다"

> "이렇게 안 좋은 장에 수익을 별로 크게 못 내거나 손실을 보더라도 저는 아무렇지 않습니다"

> "매매 금액도 엄청 줄이고 가능하면 보수적으로 접근을 해서 잘 매매하지 않으려고 하고 있습니다"

## 7. 실전 적용 체크리스트

- [ ] 코스닥 거래대금 수준으로 시장 분위기 먼저 판단하기
- [ ] 하락장에서는 매매 금액 50% 이상 축소하기
- [ ] 유통금액 작은 잡주 매매 자제하기
- [ ] 테마가 나올 때만 대장주 위주로 집중 매매하기
- [ ] 매매 안 하는 날도 시장 공부는 계속하기
