## 3. 주요 내용 정리

- 2024년 2월 8일 목요일 (설연휴 전날) 한미반도체 완벽한 매매 사례
- 설연휴 전이라 기대 안 하고 매매 쉬려 했으나 오전 10시 전 완벽한 종목 발견
- **완벽한 종목 5가지 조건**:
  1. 끼 있는 종목 (과거 상한가, 20% 상승 이력 많음)
  2. 차트 위치: 전고점 돌파하는 장대양봉
  3. 거래대금: 반도체 테마 내 최상위 (어버브보다 2배 많음)
  4. 프로그램 매매: 9시 반부터 엄청난 양 꾸준히 매수
  5. 기관 수급: 투신/연기금 지속 매수, 3차 가집계에서 급증 (14,000주→82,000주)
- 10% 조금 넘었을 때 첫 매수 → 계속 불타기로 비중 최대화
- 상한가 갈 수 있다고 판단, 최대한 매도 안 하고 버팀
- 일부 수익 실현 → 조정 시 재매수 반복
- 오전 10시 시장 상황: 반도체 테마 강세하나 수급 분산 (레인보우로보틱스, 캠, 초전도체 등도 상승)
- 한미반도체가 거래대금 2배로 압도 → 주도 테마 대장주 확신
- 10시 매수 시 종가까지 약 20% 수익 가능
- 기관/프로그램 매도 전환하면 중간 매도 계획, 하지만 계속 매수 → 끝까지 보유

## 4. 핵심 매매 전략/교훈

### 완벽한 종목 5가지 체크리스트
1. **끼 (과거 이력)**: 상한가, 20% 상승 경험 많은 종목
2. **차트 위치**: 전고점 돌파 장대양봉 (기술적 돌파)
3. **거래대금**: 테마 내 압도적 1위 (2배 이상 차이)
4. **프로그램 매매**: 9시 반부터 꾸준한 대량 매수
5. **기관 수급**: 투신/연기금 지속 매수, 가집계마다 증가

### 매매 타이밍
- **진입**: 오전 10시경, 10% 상승 후
- 너무 이른 진입보다 확신 생긴 후 진입
- 5가지 조건 모두 확인 후 최대 비중 투입

### 불타기 전략
- 첫 매수 후 계속 불타기로 비중 최대화
- 상한가 가능성 보이면 매도 자제
- 확신 있을 때는 끝까지 버티기

### 수익 실현 전략
- 물량 많을 때 일부 수익 실현
- 조정 받으면 다시 매수
- 반복 매매로 수익 극대화
- 장 후반 대부분 매도

### 주도 테마 대장주 찾기
- 테마 내 여러 종목 상승 시 거래대금 비교
- 거래대금 압도적 1위 = 대장주
- 상승률보다 거래대금이 더 중요
- 어버브 14% vs 한미 13%지만 거래대금 2배 차이 → 한미가 대장

### 수급 모니터링
- 프로그램 매매: 9시 반 이후 지속 매수 체크
- 기관: 2차, 3차 가집계마다 매수량 증가 확인
- 외국인 수급도 체크
- 매도 전환 시 즉시 손절 준비

### 변수 대응
- 기관/프로그램 매도 전환 시 중간 매도
- 하지만 계속 매수세 유지 시 끝까지 보유
- 실시간 수급 모니터링 필수

## 7. 실전 적용 체크리스트

### 1단계: 끼 확인 (과거 차트 분석)
- [ ] 과거 일봉에서 상한가 경험 있는가?
- [ ] 20% 이상 상승 이력이 여러 번 있는가?
- [ ] 강세 패턴(분홍색 캔들) 여러 개 있는가?
- [ ] 변동성이 큰 종목인가?

### 2단계: 차트 위치 확인
- [ ] 전고점 돌파 중인가?
- [ ] 장대양봉 나오는 중인가?
- [ ] 10~15% 상승 후 추가 상승 여력 있는 위치인가?
- [ ] 저항선 돌파 확인되었는가?

### 3단계: 거래대금 확인 (오전 10시경)
- [ ] 거래대금 상위 화면에서 순위 확인
- [ ] 같은 테마 내 다른 종목과 비교
- [ ] 2위와 거래대금 2배 이상 차이나는가?
- [ ] 시간이 지나도 거래대금 1위 유지하는가?

### 4단계: 프로그램 매매 확인
- [ ] 9시 반 이후 프로그램 매수 지속되는가?
- [ ] 매수량이 압도적으로 많은가?
- [ ] 프로그램 차트에서 꾸준한 매수 확인
- [ ] 11시까지 프로그램 매수세 유지되는가?

### 5단계: 기관 수급 확인
- [ ] 2차 가집계 (9시 51분): 투신/연기금 매수 확인
- [ ] 3차 가집계: 기관 매수량 급증 확인 (몇 배 증가?)
- [ ] 최근 며칠간 기관 지속 매수 이력 있는가?
- [ ] 외국인 수급도 플러스인가?

### 6단계: 주도 테마 확인
- [ ] 오늘 시장에서 어떤 테마가 강한가?
- [ ] 해당 종목이 테마 대장주인가?
- [ ] 수급이 분산되지 않고 집중되는가?
- [ ] 시간이 지나도 주도 테마 지위 유지하는가?

### 7단계: 진입 타이밍
- [ ] 5가지 조건 모두 만족하는가?
- [ ] 오전 10시경 10~15% 상승 후인가?
- [ ] 너무 이르지도, 늦지도 않은 타이밍인가?
- [ ] 확신이 생겼는가?

### 8단계: 비중 결정
- [ ] 5가지 조건 완벽 → 최대 비중 투입
- [ ] 4가지 조건 → 중간 비중
- [ ] 3가지 이하 → 소량 또는 관망
- [ ] 불타기 준비 (추가 매수 자금 확보)

### 9단계: 보유 전략
- [ ] 상한가 가능성 있으면 끝까지 버티기
- [ ] 물량 많으면 일부 수익 실현
- [ ] 조정 받으면 재매수 고려
- [ ] 프로그램/기관 매도 전환 시 즉시 손절

### 10단계: 실시간 모니터링
- [ ] 프로그램 매매 지속 확인 (30분마다)
- [ ] 기관 매수세 유지 확인 (가집계마다)
- [ ] 거래대금 순위 변화 체크
- [ ] 주도 테마 대장주 지위 유지 확인

### 11단계: 청산 타이밍
- [ ] 장 후반 (2시 이후) 대부분 매도 고려
- [ ] 수급 악화 시 즉시 청산
- [ ] 상한가 근접 시 일부 남기고 매도
- [ ] 익일 갭 상승 기대 시 일부 오버나잇

### 주의사항
- [ ] 5가지 조건 중 하나라도 빠지면 "완벽한 종목" 아님
- [ ] 설연휴 같은 변수 있어도 조건 맞으면 과감히 진입
- [ ] 확신 없으면 최대 비중 금지
- [ ] 수급 변화에 민감하게 반응
- [ ] 과거 끼 없는 종목은 아무리 좋아도 제외
