## 3. 주요 내용 정리

**[00:00~01:00] 4대 일봉자리 소개 - 불변의 법칙**
- 일봉자리가 자기 기준에 들어와야 매매 가능
- 대장주라도 일봉자리가 안 좋으면 보통 못 함 → 다른 종목으로 체인지

**[01:00~02:30] 뉴스 해석 관점**
- 내가 생각하는 좋은 뉴스는 의미 없음 → 누가 봐도 좋아야 함
- 최근 시장에서 강했던 섹터에서 새로운 뉴스가 나왔을 때가 1순위
- 최근 가지도 않았던 테마에 좋은 뉴스 있어도 밑꼬리 대고 떨어짐

**[02:30~03:52] 대장주 엇박 탔을 때 해결법**
- "지금 종목을 하나도 안 가지고 있는 상태에서 뭘 살까" 생각하기
- 보유 종목에 긍정 편향이 생기므로 무포지션 관점에서 판단
- 상승률 역전된다고 바로 갈아타지 말고 일봉 위치, 수급, 끼 등 종합적 판단
- 엇박 해결의 간단한 방법: 빠른 손절 후 대장주 갈아타기

**[03:52~05:17] 4대 일봉자리 상세 설명**
1. **전고점 도전하러 가는 자리**: 위에 매물대가 없어지는 자리
2. **신고가**: 일봉상 계속 신고가를 달리는 종목
3. **빈집털이(갭 구간)**: 매물대가 얇은 구간, 갭이 뚫린 구간
4. **바닥자리**: 저점에서의 매매
- 이 4가지 안에서만 매매 → 80%가 걸러지고 나머지 20%에서 주도주 선별

**[05:17~07:11] 불타기(추가매수) 주의**
- 불타기는 양날의 검: 잘되면 수익 극대화, 잘못되면 뒤집힘
- 단점 1: 평단가가 올라감 → 조금만 밀려도 손절
- 단점 2: 심리적 부담 증가 → 종목에게 지고 들어감
- 장점: 수익금이 커진다 (유일한 장점)
- 결론: 불타기보다 좋은 종목을 분할매수하는 것이 낫다

**[07:11~09:46] 양지주/음지주 분류법과 2등주 매매**
- 양지주: 실적 기반, 시총 3천억 이상
- 음지주: 스몰캡, 시총 1~2천억, 실적 부족 (정치테마 등)
- 같은 테마 안에서 양지 대장 + 음지 대장 각각 매매
- 2등주는 거래대금이 충분하고 메리트가 있을 때만 매매
- 분봉상 거래대금이 10억도 안 되는 종목은 매매 안 함

## 4. 핵심 매매 전략/교훈

1. **4대 일봉자리 필터링**: 전고점 도전, 신고가, 빈집털이, 바닥자리에서만 매매
2. **뉴스 1순위 판단법**: 최근 강했던 섹터에 새 뉴스가 추가될 때
3. **엇박 해결**: 무포지션 관점에서 "지금 뭘 살까" 생각 후 손절/갈아타기
4. **불타기 자제**: 평단가 상승과 심리적 부담 > 수익 극대화 장점
5. **양지/음지 분류**: 같은 테마에서도 시총 기준으로 나눠서 각각의 대장주 매매

## 7. 실전 적용 체크리스트

- [ ] 매매 전 일봉 차트를 확인하고 4대 일봉자리(전고점도전/신고가/빈집털이/바닥자리)에 해당하는지 체크한다
- [ ] 뉴스 판단 시 "최근 강했던 섹터 + 새 뉴스"를 1순위로 본다
- [ ] 엇박을 탔을 때 무포지션 관점에서 "지금 뭘 살까" 생각해본다
- [ ] 불타기(추가매수)는 원칙적으로 하지 않는다
- [ ] 종목을 양지주(시총 3천억+)와 음지주(시총 1~2천억)로 분류해 각각 대장주를 찾는다
- [ ] 분봉상 거래대금이 10억 미만인 종목은 매매하지 않는다
- [ ] 2등주는 거래대금과 등락률에서 메리트가 있을 때만 매매한다
