계엄/탄핵 이슈로 정치 테마주가 초강세를 보이는 시장에서, 테마주를 찾는 3가지 방법(HTS 뉴스, 차트 비교, 종목 토론실)을 실전으로 보여주고, 이재명 테마주와 한동훈 테마주 종목 리스트를 정리한다.

## 3. 주요 내용 정리

### [00:04~01:40] 방법 1: HTS 뉴스로 테마 확인
- 거래대금 상위에서 5% 이상 상승한 종목 확인
- 해당 종목의 **HTS 뉴스**에서 정규장 이전 뉴스 검색
- 카카오페이 사례: "윤 대통령 탄핵 가능성에 급등" 뉴스 → 윤석열 탄핵 관련주로 판단
- 뉴스 제목 키워드만으로 테마 추정 가능

### [01:40~02:12] 방법 2: 동일 테마주 차트 비교
- 카카오페이와 카카오의 최근 3일 일봉 차트가 거의 동일
- **동일 테마주는 비슷한 차트 흐름**으로 움직임
- 뉴스 + 차트 흐름 비교로 테마 확인 가능

### [02:12~04:05] 이재명/한동훈 테마주 뉴스 분석
- 동신건설(25% 상승): HTS 뉴스에서 "이재명 테마주 급등" 확인
- 뉴스 내용에서 관련 종목 리스트도 함께 확인 가능 (오리엔트정공, 에이텍, 이스타코, 일성건설 등)
- 한동훈 테마주도 같은 뉴스에서 확인: DTNC, 대상홀딩스, 오파스넷, 태양금속

### [04:05~04:55] 분봉 차트로 동시 움직임 확인
- 동신건설, 에이텍, 카카오페이 모두 금요일 9시 30분경 동시 급등
- 같은 테마주는 같은 시점에 움직이는 특성 확인

### [04:55~05:52] 방법 3: 네이버 증권 종목 토론실
- HTS 뉴스를 빠르게 확인할 수 없을 때 활용
- 네이버 증권 → 종목 검색 → 종목 토론실 진입
- 사람들이 적어둔 글 키워드로 테마 빠르게 파악 (탄핵, 윤대통령, 한동훈 등)
- 토론실 글은 가치 없는 글이 대부분이지만 **테마 파악용으로는 유용**

### [05:52~07:06] 이재명/한동훈 테마주 종목 리스트
- **이재명 테마주**: 오리엔트정공, 이스타코, 동신건설, 일성건설, 에이텍, 코이즈, 토탈소프트, CS, 수산INT, 에텍모빌리티, 형지엘리트, 카스, 코나아이, 형지INC, 오리엔트바이오, 프리엠스, 서인바이오
- **한동훈 테마주**: DTNC, 대상홀딩스, 오파스넷, 태양금속, 부방, 체시스

### [07:06~07:25] 주의사항
- 뉴스 결과 나오기 전 테마주에 홀짝 배팅하면 큰 손실 위험
- 애매할 때는 매매 자제

## 4. 핵심 매매 전략

- **테마 찾기 3단계**: HTS 뉴스 확인 → 차트 비교로 검증 → 종목 토론실로 보완
- **거래대금 상위 + 5% 이상 상승 종목**: 테마 탐색의 출발점
- **동일 테마주 차트 동조화**: 같은 테마주는 같은 타이밍에 비슷한 차트 형성
- **뉴스 키워드 빠르게 파악**: HTS 뉴스 제목만으로 테마 추정
- **정치 테마 주의**: 뉴스 결과에 따라 급등/급락 가능, 홀짝 배팅 금지

## 6. 명언 / 핵심 발언

> "동일 테마주는 비슷한 차트 흐름을 보이면서 움직이기 때문에 뉴스와 차트를 통해 어떤 테마에 속하는지 확인해 볼 수 있습니다."

> "종목 토론실 글은 가치 없는 글이 대부분이지만 빠르게 테마를 찾는데 활용하실 수 있습니다."

> "뉴스의 결과가 나오기 전 테마주에 홀짝 배팅하는 것은 잘못될 경우 큰 손실을 보실 수 있으니 애매하신 때 항상 유의하셨으면 좋겠습니다."

## 7. 체크리스트

- [ ] 거래대금 상위에서 5% 이상 상승 종목을 확인했는가
- [ ] 해당 종목의 HTS 뉴스(정규장 이전)를 확인하여 테마를 파악했는가
- [ ] 동일 테마 의심 종목의 일봉/분봉 차트를 비교했는가
- [ ] 차트 동조화(같은 시점 급등)로 테마를 검증했는가
- [ ] 네이버 종목 토론실 키워드로 보조 확인했는가
- [ ] 정치 테마주의 경우 뉴스 결과 전 홀짝 배팅을 피했는가
- [ ] 관련 종목 리스트를 관심종목에 등록하여 실시간 모니터링하고 있는가
