## 3. 주요 내용 정리

### [00:00~10:00] 현재 시장 상황 분석
- 시장이 전반적으로 좋지 않은 상황에서의 대응법
- 거래대금이 줄어든 시장에서는 매매 횟수를 줄여야 함
- 강한 테마에만 집중하고 나머지는 쉬어가기

### [10:00~20:00] 실제 매매 타점 공개
- 실전 매매 화면을 보여주며 진입/청산 타점 설명
- 분봉 차트 기반의 매수/매도 포인트 분석
- 호가창과 거래대금을 보며 실시간으로 판단하는 과정

### [20:00~29:35] Q&A - 시청자 질문 답변
- 시장이 안 좋을 때 수익내는 방법
- 손절 기준과 손절 실행의 중요성
- 초보자가 가장 먼저 배워야 할 것

## 4. 핵심 매매 전략/교훈

1. **시장 상황에 맞는 매매**: 시장이 좋지 않으면 매매 횟수를 줄이고 선별적으로 진입
2. **타점의 중요성**: 어떤 종목을 사느냐보다 어디서 사느냐가 더 중요
3. **휴식도 매매**: 좋은 기회가 없으면 쉬는 것도 전략
4. **실시간 판단력**: 호가창, 거래대금, 분봉 패턴을 종합적으로 보고 판단
