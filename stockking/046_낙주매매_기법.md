## 3. 주요 내용 정리

**[00:00~00:36] 낙주매매 개요**
- 거래대금 폭발 종목을 활용한 높은 확률의 낙주매매 기법
- 자주 하는 매매는 아니지만 조건 충족 시 높은 성공률

**[00:36~01:02] 조건 1: 거래대금 5천억 이상 인기 종목**
- 하루 거래대금 5천억 이상 유지되는 상승 추세의 인기 종목만 대상
- 아무 종목이나 낙주매매하면 안 됨
- 제주반도체 사례: 최근 일주일 5천억 이상 거래대금 유지

**[01:02~01:38] 조건 2: 분봉 하락 기울기가 가파른 종목**
- 1분봉 기준 하락 기울기가 가파르게 전일 종가까지 하락해야 함
- 제주반도체: +10%에서 급한 기울기로 하락
- 서서히 계단식 하락하는 종목은 낙주매매 성공 확률 낮음

**[01:38~02:24] 조건 3: 매수 포인트 - 전일 종가 근처**
- 전일 종가 대비 -1% ~ +1% 사이에서 매수
- 정확히 어디까지 떨어질지 모르므로 유연하게 대응
- 제주반도체 사례: 전일 종가 33,800원 → 33,400~33,900원에서 매수

**[02:24~03:25] 조건 4: 주도 테마 대장주 여부에 따른 목표가**
- 대장주(코세스 등): V자 반등으로 하락폭 전부 회복 가능
- 대장주 아닌 종목(제주반도체): 바닥에서 2~3% 상승 시 수익 실현
- 분할 매도로 수익 실현

**[03:25~05:06] 조건 5~6: V자 반등 필수 + 손절 기준**
- 조건 5(5번째): 대장주라면 하락폭 전부 회복 가능
- 조건 6: 반드시 V자 반등해야 함 → 옆으로 기면 지지 실패 → 급락 가능
- 한 번 더 바닥 터치는 OK, 여러 번 내려가면 빠른 손절 필요

**[05:06~06:58] 조건 7: 전일 종가 대비 -1% 이상에서 빠른 반등 못하면 매도**
- -1% 이하에서 오래 유지되면 지지 실패 확률 높음
- 키움증권 약세 패턴 설정법: 수식 관리자 → 강세/약세 → 전일 종가의 99% 이하 시 하늘색 표시
- 제주반도체: 잠시 -1% 이하 내려갔지만 빠르게 반등 성공
- V자 반등 못하거나 -1% 이하 장시간 유지 시 빠르게 손절 필수

## 4. 핵심 매매 전략/교훈

1. **7가지 조건 모두 충족 시에만 낙주매매**: 거래대금 5천억+ / 가파른 하락 / 전일 종가 근처 매수 / 대장주 여부 확인 / V자 반등 / -1% 이상 유지
2. **전일 종가가 핵심 지지선**: 급락 후 전일 종가 근처에서 V자 반등 노림
3. **대장주 vs 비대장주 목표가 차이**: 대장주는 하락폭 100% 회복, 비대장주는 2~3% 수익 실현
4. **빠른 손절이 리스크 관리 핵심**: V자 반등 실패 시 즉시 시장가 매도
5. **약세 패턴 설정 활용**: 키움증권 차트에서 전일 종가 -1% 이하 시각화

## 6. 명언/핵심 문장

> "아무 종목이나 낙주 매매를 하면 안 되고 이렇게 거래대금이 폭발하고 있는 종목을 활용하셔야 됩니다."

> "분봉의 하락 기울기가 가팔라지며 전일 종가까지 하락한 종목이 공략하기가 가장 좋습니다. 서서히 계단식 하락을 하는 종목은 낙주 매매에 성공할 확률이 낮습니다."

> "전일 종가 근처를 터치한 뒤에 빠르게 V자 반등을 하지 않으면 시장가로 매도해야 됩니다."

> "성공 확률이 정말 높은 방법이지만 V자 반등을 하지 못하거나 -1% 이하에서 주가가 오랫동안 유지된다면 손실을 크게 보실 수 있으니 빠르게 손절해서 리스크 관리만 잘하신다면 꾸준히 수익을 쌓아 나가실 수 있는 기법이 될 것입니다."

## 7. 실전 적용 체크리스트

- [ ] 낙주매매 대상: 최근 일주일 거래대금 5천억 이상 유지되는 상승 추세 종목만 선정
- [ ] 분봉 차트에서 하락 기울기가 가파른지 확인한다 (계단식 하락은 제외)
- [ ] 매수 구간: 전일 종가 대비 -1% ~ +1% 사이에서 분할 매수한다
- [ ] 대장주 여부에 따라 목표 수익률을 설정한다 (대장주: 하락폭 회복 / 비대장주: 2~3%)
- [ ] V자 반등이 발생하지 않고 옆으로 기면 즉시 시장가 매도한다
- [ ] 전일 종가 대비 -1% 이하에서 빠르게 반등하지 못하면 시장가 매도한다
- [ ] 키움증권 약세 패턴(전일 종가 99% 이하 = 하늘색)을 설정하여 시각적으로 확인한다
