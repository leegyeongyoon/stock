# 095. 오르는 주식 사는 법 '이렇게' 하세요

## 1. 영상 개요
- **한줄 요약:** 거래대금 상위에서 주도 테마와 대장주를 찾고, 대장주가 변경될 때 빠르게 대응하는 방법
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2024-08-28
- **영상 길이:** 30분 16초
- **원본 URL:** https://www.youtube.com/watch?v=nPP3LuFSkPg

## 2. 핵심 키워드
`#주도테마` `#대장주찾기` `#거래대금상위` `#테마매매` `#코로나19` `#전기차화재` `#대장주변경` `#상한가` `#등락률` `#초보강의`

## 3. 주요 내용 정리

### [00:00~05:00] 테마 찾기 - 거래대금 상위 활용
- 거래대금 상위 화면에서 등락률 높은 종목 확인
- 같은 테마 종목이 다수 상위에 있으면 그 테마가 주도 테마
- 2024년 8월: 코로나19 테마, 전기차 화재 테마 강세

### [05:00~10:00] 대장주 찾는 법
- 상승률이 가장 높은 종목 = 대장주
- 아침 일찍 상한가 간 종목이 진짜 대장주일 수 있음
- 거래대금 상위에 없어도 상한가로 거래 안 된 종목 체크

### [10:00~20:00] 대장주 매매 실전
- 특정 테마로 수급이 쏠리는 날을 공략
- 수급 분산되는 날보다 한 테마에 집중되는 날이 수익 확률 높음
- 대장주가 바뀌면 빠르게 새로운 대장주로 이동

### [20:00~30:00] 대장주 변경 대응법
- 기존 대장주 매매자들이 새 대장주로 옮겨타려 함
- 대장주 변경 시 빠른 대응이 핵심
- 금융주 등 변동성 낮은 대형주는 단타 부적합

## 4. 핵심 매매 전략/교훈

1. **거래대금 상위에서 주도 테마 찾기** - 등락률 높은 종목들의 공통 테마 확인
2. **대장주 = 상승률 1위 종목** - 상한가 간 종목 우선 체크
3. **수급이 한 테마에 쏠리는 날 공략** - 분산되는 날은 회피
4. **대장주 변경 시 빠르게 갈아타기** - 기존 종목에 미련 갖지 말 것
5. **변동성 없는 대형주는 단타 부적합** - 끼 있는 종목만 공략

## 6. 명언/핵심 문장

> "대장주가 만약에 변경이 된다면 기존 대장주를 매매하고 있는 사람들은 새로운 대장주로 다 옮겨타고 싶어하기 때문에 빨리 대응하는게 중요합니다."

> "단기 매매로 좀 높은 확률로 수익을 내려면 이렇게 특정 테마가 확실히 강한 날을 공략하면 수익을 낼 확률이 많이 높아집니다."
