## 3. 주요 내용 정리

### [00:00~03:00] 주도 테마 대장주 찾기
- 거래대금 상위에서 등락률 높은 종목 확인
- 셀트리온 1조3천억 + 셀트리온제약 5,500억 = 거래대금 1,3등
- 셀트리온제약: 전고점 돌파 장대양봉 + 수급 좋음 = 주도 테마 대장주

### [03:00~06:00] 2개 계좌 전략
- 데이트레이딩 계좌: 분봉상 좋은 자리마다 매수/익절 반복 → 793만원 수익
- 오버나잇 계좌: 주도 테마 대장주 매수 → 다음날까지 보유 → 갭상승 수익
- 오버나잇 조건: 주도 테마 대장주 + 전고점 돌파 장대양봉 + 수급

### [06:00~09:00] 다음날 대응법
- 갭상승 시: 5~10% 상승 때 수익 실현
- 갭하락 시: 시초가에 즉시 매도
- 전일 종가까지 조정 시: 지지선 역할 → 반등 매매 기회

## 4. 핵심 매매 전략/교훈

1. **계좌 2개 분리 운용** - 데이트레이딩 + 오버나잇 각각의 역할
2. **주도 테마 대장주만 오버나잇** - 다음날 갭상승 확률 높음
3. **전일 종가 = 강력한 지지선** - 조정 시 반등 매매 포인트
4. **갭하락 시 시초가 즉시 매도** - 악재 가능성 인정
5. **거래대금 상위에서 테마 찾기** - 가장 기본적이면서 효과적인 방법
