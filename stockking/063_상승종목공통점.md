## 2. 핵심 키워드

- 강세 패턴 설정
- 거래대금 1000억
- 시초가 대비 10% 상승
- 분홍색 캔들
- 키움증권 수식 관리자
- 상승 특성
- 지지 저항 자리
- 한미반도체
- HLB
- 삼성전자 변동성

## 3. 주요 내용 정리

- 홍인기 차트의 분홍색 선: 강한 상승 캔들 표시 (거래대금 1000억+ & 시초가 대비 10%+ 상승)
- 한 번 강하게 오른 주식은 다음에도 쉽게 오르는 경향
- 반대로 항상 오르다 떨어지는 종목은 그런 특성 지속 (대량 물량 보유자가 계속 매도 등)
- 종목마다 고유한 상승/하락 특성 존재
- **강세 패턴 설정 방법 (키움증권)**:
  1. 0600번 키움 종합 차트에서 우클릭
  2. 수식 관리자 → 강세 약세 → 사용자 강세 약세 → 새로 만들기
  3. 이름: "1천억 10%"
  4. 수식 입력: `거래대금>100000 AND C>O*1.1`
     - 거래대금 단위는 100만원, 100000 = 1000억
     - C(종가) > O(시초가) * 1.1 (10% 상승)
  5. 수식 검증 후 작업 저장
  6. 차트에서 우클릭 → 강세 약세 적용
- 한미반도체, HLB 등은 강세 패턴 많음 = 쉽게 상승하는 종목
- 삼성전자는 강세 패턴 없음 = 하루 10% 상승 어려움 = 단타에 부적합
- 삼성전자는 장기투자는 OK, 단타는 변동성 낮아 세금 내면 수익 적음
- 강세 패턴 많은 종목이 단기매매에 유리
- 지지/저항 자리에서 뚫고 갈지 여부 확인 중요 (구체적 내용은 영상 후반부)

## 4. 핵심 매매 전략/교훈

### 종목 선정의 핵심
- **강세 패턴 많은 종목 선택**: 과거 강한 상승 이력 = 미래 상승 가능성 높음
- 거래대금 1000억+ & 10% 이상 상승 경험 많은 종목
- 종목마다 고유 특성 있음 → 차트로 빠르게 파악

### 피해야 할 종목
- 항상 오르다 떨어지는 종목 (대량 물량 보유자 존재 가능)
- 강세 패턴 없는 대형주 (삼성전자 등)
- 변동성 낮은 종목 (세금 내면 수익 미미)

### 단타에 유리한 종목
- 하루 10% 이상 자주 움직이는 종목
- 거래대금 1000억 이상 자주 터지는 종목
- 강세 패턴이 여러 개 나온 종목 (한미반도체, HLB 등)

### 차트 설정 활용
- 강세 패턴을 시각화하면 종목 특성 빠르게 파악
- 분홍색 캔들 많은 종목 = 상승 끼 있음
- 차트만 봐도 단타 적합성 즉시 판단 가능

### 장기투자 vs 단타
- 삼성전자 같은 종목: 장기투자 OK, 단타 NO
- 단타는 변동성 + 거래대금이 핵심
- 세금 고려하면 변동성 낮은 종목은 수익 어려움

## 5. 주요 종목/섹터 언급

| 종목명 | 특징 | 언급 내용 |
|--------|------|-----------|
| **한미반도체** | 반도체 | 강세 패턴 3개 출현, 상승 끼 있는 종목 |
| **HLB** | 바이오 | 강세 패턴 많이 나옴, 쉽게 상승하는 종목 |
| **삼성전자** | 반도체 | 강세 패턴 없음, 단타 부적합, 장기투자는 가능 |

## 6. 명언/핵심 문장

> "보통 이렇게 한 번에 많이 오른 경향이 있는 주식들은 다음에도 또 쉽게 오르는 경향이 있고"

> "반대로 어떤 종목은 올라갔다 하면 맨날 떨어지는 종목이 있어요. 근데 그런 종목은 또 이게 특성이 남아 있어서"

> "주식들의 좀 특성이 있거든요. 그런 거를 빠르게 파악하기 위해서 이렇게 분홍색 선으로 표시를 해 놨습니다"

> "거래대금이 1,000억이 넘으면서 시초가 대비 종가가 10% 이상 상승한 캔들을 분홍색으로 표시되게 해 놨습니다"

> "삼성전자가 안 좋은 주식이라는 뜻은 아니지만 하루에 10% 이상 이렇게 올라가기는 어려운 주식이라는 거를 보여 주는 거"

> "단기 매매에서 삼성전자로 단타를 하기에는 이게 하루 변동성이 너무 낮아서 세금을 맨날 내다 보면 별로 수익이 안 날 때가 많아요"

> "강세 패턴이 많이 나오는 종목을 매매를 할수록 상승할 만한 자리에서 더 쉽게 상승을 할 수가 있고 높은 수익률을 낼 수 있는 경우가 많습니다"

## 7. 실전 적용 체크리스트

### 강세 패턴 설정 (키움증권 기준)
- [ ] 키움증권 0600번 화면 (종합 차트) 열기
- [ ] 차트에서 우클릭 → "수식 관리자" 선택
- [ ] "강세 약세" 메뉴 → "사용자 강세 약세" 선택
- [ ] "새로 만들기" 클릭
- [ ] 이름 입력: "1천억 10%" (또는 원하는 이름)
- [ ] 강세 패턴 수식 입력: `거래대금>100000 AND C>O*1.1`
- [ ] "수식 검증" 클릭 → "수식에 이상이 없습니다" 확인
- [ ] "작업 저장" 클릭
- [ ] 차트로 돌아가서 우클릭 → "강세 약세 적용"
- [ ] "1천억 10%" 선택 후 적용

### 수식 이해하기
- [ ] `거래대금>100000`: 100만원 단위로 10만 = 1000억원
- [ ] `C>O*1.1`: C(종가) > O(시초가) * 1.1 (10% 상승)
- [ ] `AND`: 두 조건 모두 만족
- [ ] 수식 변경 가능: 2000억 15% 등 자유롭게 조정

### 종목 선정 체크
- [ ] 관심 종목들의 차트에 강세 패턴 적용
- [ ] 분홍색 캔들 개수 확인 (많을수록 상승 끼 있음)
- [ ] 최근 3개월 내 강세 패턴 2개 이상 = 단타 적합 종목
- [ ] 강세 패턴 없는 종목 = 단타 부적합 (변동성 낮음)

### 단타 적합성 판단
- [ ] 거래대금이 자주 1000억 이상 터지는가?
- [ ] 하루 10% 이상 상승 경험이 최근 있는가?
- [ ] 강세 패턴이 여러 개 나타나는가?
- [ ] 시가총액이 너무 크지 않은가? (대형주는 변동성 낮음)

### 피해야 할 종목 체크
- [ ] 강세 패턴 후 항상 하락하는 패턴 반복
- [ ] 대량 물량 보유자가 계속 매도하는 종목
- [ ] 변동성 낮은 초대형주 (삼성전자 등)
- [ ] 거래대금 300억 이하 소외 종목

### 종목별 특성 파악
- [ ] 최근 6개월 차트 분석
- [ ] 강세 패턴 출현 빈도 확인
- [ ] 강세 패턴 후 추가 상승 여부 확인
- [ ] 하락 패턴도 설정하여 약세 특성 파악

### 추가 설정 아이디어
- [ ] 약세 패턴도 동일 방식으로 설정 (하락 종목 필터링)
- [ ] 거래대금 2000억+ 15% 상승 (더 강한 조건)
- [ ] 거래대금 500억+ 5% 상승 (더 약한 조건, 참고용)
- [ ] 여러 강세 패턴 설정하여 비교 분석

### 실전 매매 적용
- [ ] 강세 패턴 많은 종목으로 관심종목 리스트 구성
- [ ] 매일 아침 강세 패턴 종목들의 수급 체크
- [ ] 강세 패턴 나온 후 조정 받은 자리에서 진입 고려
- [ ] 강세 패턴 없는 종목은 단타 대상에서 제외

### 지지/저항 함께 활용
- [ ] 강세 패턴 + 지지선 돌파 = 강한 매수 신호
- [ ] 강세 패턴 + 저항선 접근 = 단기 차익 실현 고려
- [ ] 패턴과 기술적 분석 조합하여 승률 높이기

### 주의사항
- [ ] 강세 패턴이 많다고 무조건 매수 금지 (타이밍 중요)
- [ ] 최근 패턴인지 오래된 패턴인지 확인
- [ ] 시장 전체 분위기와 함께 고려
- [ ] 거래대금 조건이 현재 상황과 맞는지 점검
