# 096. 천천히 가는 길이 가장 빠른 길이다

- **채널명:** 대왕개미 홍인기
- **업로드일:** 2025-12-13
- **영상 길이:** 10분 53초

## 2. 핵심 키워드
`#데이트레이딩` `#매매원칙` `#D+0` `#D+1` `#계좌확인금지` `#심리관리` `#오전장매매` `#이등주매매` `#하락장대응` `#황금기앱`

## 3. 주요 내용 정리

### [00:00~02:00] 데이트레이딩이 최고인 이유
- 하락장에서도 손실 안 나는 장점
- 원칙만 지키면 돈은 따라옴
- 계좌 수익/손실에 일희일비하면 돈을 쫓는 매매 = 100% 실패

### [02:00~04:00] D+0, D+1 매매만으로 충분
- 첫 장대양봉일 = D+0, 다음날 갭뜨면 = D+1
- D+1에는 진짜 센 종목만, 종목 선정이 핵심
- 대장주 점상 시 이등주 매매 조건: 테마 세기에 따라 판단

### [04:00~07:00] 오전장이 오후장보다 유리한 이유
- 오전장에 수급이 몰림 → 짧게 먹고 빠지기 유리
- 황금기 앱 소개: 주도 섹터 + 대장주 + 거래대금 한눈에 파악
- 직장인도 활용 가능

### [07:00~11:00] 원칙 준수의 중요성
- 당일 손익 금액 안 보는 원칙 (생각보다 어려움)
- 2년 이상 해보고 가능성 없으면 단기매매 손절할 것
- 매매 금액 급격히 올리지 말고 수익금 일부는 출금

## 4. 핵심 매매 전략/교훈

1. **데이트레이딩은 원칙 준수가 전부** - 원칙 지키면 돈은 따라옴
2. **D+0, D+1만 해도 충분** - 욕심 부리지 말 것
3. **오전장 집중** - 수급이 몰리는 시간대에 매매
4. **당일 손익 금액 확인 자제** - 금액을 쫓으면 감정적 매매
5. **이등주는 테마가 확실히 강할 때만** - 대장주 점상 + 후발주 갭상승 시
