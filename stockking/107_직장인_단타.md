# 107. 직장인 단타, 저라면 '이때' 주식 매수합니다

## 3. 주요 내용 정리

### [00:00~05:00] 직장인 단타의 현실
- 장중 매매 어려움 → D+1 매매가 가장 적합
- 전일 주도 테마 대장주가 다음날도 강세 보일 확률 높음
- 아침 출근 전 8:30~9:00 장전 시간외 활용

### [05:00~10:00] 구체적 매매 방법
- 전일 거래대금 상위에서 주도 테마 대장주 확인
- 장전 시간외(8:30~8:40)에 전일 종가로 매수 시도
- 시초가에 갭상승 확인 후 추가 매수 or 수익 실현

### [10:00~13:00] 주의사항
- 직장인은 매매 횟수 제한적 → 종목 선정이 더 중요
- 갭하락 시 손절 기준 미리 설정
- 예약 매도 주문 활용하여 장중 대응

## 4. 핵심 매매 전략/교훈

1. **직장인은 D+1 매매에 집중** - 전일 주도주 다음날 공략
2. **장전 시간외(8:30~8:40) 활용** - 전일 종가에 매수 시도
3. **예약 매도 주문 필수 설정** - 장중 대응 불가 시 안전장치
4. **종목 선정이 가장 중요** - 매매 횟수 제한적이므로 정밀 선정
5. **갭하락 시 시초가 손절 기준 미리 설정** - 감정적 판단 방지
