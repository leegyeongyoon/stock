# 122. 뉴스가 나오면 어떻게 대응해야할까

뉴스 기반 매매에 대한 홍인기의 접근법을 설명하는 영상. 기본적으로 뉴스만 보고 매매하지 않으며 거래대금과 수급을 우선 확인하되, 정말 강한 뉴스(카페24 구글 투자, 이스라엘 전쟁)에는 예외적으로 뉴스만 보고 매매하는 사례를 소개한다.

## 3. 주요 내용 정리

### [00:00~01:08] 매매 시 뉴스 활용 원칙
- 뉴스만 보고 바로 매수하는 일은 거의 없음
- 좋은 뉴스라도 수급이 붙어야 상승 → 외국인/프로그램 대량 매도 시 하락
- **기본 순서**: 거래대금으로 관심 종목 확인 → 해당 종목의 뉴스 확인

### [01:08~02:08] 뉴스 확인 이유
- 뉴스의 **지속력**: 얼마나 오래 테마가 유지될지 판단
- 뉴스의 **세기**: 얼마나 상승할 수 있을지 판단
- 에코프로 머티 사례: 특별한 뉴스 없이 연기금 56만 주 매수만으로 20% 상승

### [02:27~04:01] 예외: 정말 센 뉴스 - 카페24
- 구글의 삼자배정 유상증자 → 점상(상한가 시작) → 수량 배분으로 소량 매수
- 다음날도 상한가 시작 → 눌림에 추가 매수
- **빅테크의 국내 기업 지분 투자가 처음** → 레인보우 로보틱스(삼성 투자) 보다 더 큰 뉴스로 판단

### [04:01~05:50] 예외: 정말 센 뉴스 - 이스라엘 전쟁
- 전쟁은 바로 끝날 이슈가 아님 → 러시아-우크라이나 때 사료주 급등 경험
- 어떤 종목이 대장주가 될지 미리 알 수 없음 → 장 시작 후 대장주 발견 시 매수
- 흥구석유가 가장 많이 오른 대장주로 확인 → 상한가 근처 매수 → 다음날도 급등

### [05:50~06:43] 뉴스 매매는 경험이 중요
- 과거 비슷한 사례 경험이 있어야 센 뉴스를 판단 가능
- 카페24: 레인보우 로보틱스(삼성 투자) 경험이 있었기에 빠른 판단
- 흥구석유: 러시아-우크라이나 전쟁 때 사료주 급등 경험 활용

### [06:43~07:35] 특징주 뉴스에 대한 경계
- 특징주 뉴스는 주가 띄우려고 오버해서 작성하는 경향
- 보유 종목에 특징주 뉴스가 떠서 올라가면 오히려 매도 기회
- **뉴스만 보고 급하게 매수하면 큰 손실 위험**

## 4. 핵심 매매 전략

- **수급 > 뉴스**: 거래대금과 수급을 먼저 확인하고, 뉴스는 보조 참고 자료
- **센 뉴스 판별법**: 빅테크 투자, 전쟁/지정학 이슈 등 전례 없는 규모의 뉴스
- **센 뉴스 대응**: 장 시작 후 대장주 확인 → 적극 매수 (미리 종목 특정 불가 시)
- **특정 종목 뉴스 시**: 해당 종목이 정해져 있으면 눌림에 매수 (카페24 방식)
- **특징주 뉴스 경계**: 오히려 보유 종목 매도 기회로 활용

| 흥구석유 | 강세 (매매) | 이스라엘 전쟁 대장주, 상한가 근처 매수 후 다음날 급등 |
| 레인보우 로보틱스 | 참고 | 삼성 투자 시 급등 사례, 카페24 비교 기준 |

## 6. 명언 / 핵심 발언

> "이게 뉴스가 진짜 정말로 좋은 뉴스라고 하더라도 주식이라는게 수급이 붙어야 올라갈 수 있잖아요. 결국에 돈 많은 사람이 사면 올라가고 돈 많은 사람이 팔면 내려가는게 주식입니다."

> "특징주 뉴스 같은 거는 그냥 단기간에 주가를 띄우려고 좀 오버해서 쓰는 경향이 있기 때문에 오히려 만약에 가지고 있던 종목이 특징주 뉴스가 떠 가지고 올라가면 그럴 때 파는 경우가 더 많은 거 같습니다."

> "어디서 배운다기보다는 경험을 좀 많이 쌓으셔야 합니다."

## 7. 체크리스트

- [ ] 뉴스만 보고 즉시 매수하지 않고 거래대금/수급을 먼저 확인했는가
- [ ] 뉴스의 지속력(얼마나 오래 갈지)과 세기(얼마나 올라갈지)를 판단했는가
- [ ] 정말 센 뉴스인지 과거 유사 사례와 비교하여 판단했는가
- [ ] 특징주 뉴스에 의한 뇌동 매수를 하지 않았는가
- [ ] 보유 종목에 특징주 뉴스가 뜨면 매도 기회로 활용했는가
- [ ] 센 뉴스 시 대장주 확인 후 매수 원칙을 지켰는가
