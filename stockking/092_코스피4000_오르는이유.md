# 092. 코스피 4000, 이렇게 오르는 이유

## 1. 영상 개요
코스피 4,000 돌파를 앞둔 상황에서 지수 급등의 원인(외국인/기관 대량 매수, 고객예탁금 사상 최고), 매매 전략(2차전지 테마 집중), 애프터마켓 급락 매매 사례를 분석하는 영상.

- **업로드일**: 2025-10-26
- **영상 길이**: 9분 22초

## 3. 주요 내용 정리

### [00:00~04:00] 코스피 급등 원인 분석
- 코스피 10월 초 3,500 -> 3,900 이상으로 조정 없이 급등
- **외국인**: 5조원 매수 / **기관**: 2조원 매수 / **개인**: 7조원 매도
- 고객예탁금 80조원 = 사상 최고 수준 (코로나 유동성 장세보다 높음)
- 개인이 아직 본격 매수하지 않음 -> 대기 자금 풍부

### [04:00~06:30] 시장 전망과 리스크
- 지수가 단기간 72% 급등하여 부담감 큼
- 하지만 외국인/기관이 아직 매수 지속 중 (개인 과열 아님)
- 부동산 규제로 갈 곳 잃은 자금이 주식 시장으로 유입 가능성
- 정부의 코스피 5,000 의지도 강한 상황
- 결론: 많이 올랐지만 유동성 측면에서 큰 조정은 어려울 수도 있음

### [06:30~09:22] 매매 사례와 실전 전략
- **금요일 매매**: 2차전지 테마가 압도적 주도 -> 포스코퓨처엠(2,800만원 수익), 중앙첨단소재(700만원 수익)
- **핵심 판단 포인트**: (1) 외국인+기관 대량 매수 -> 장 마감까지 강세 확률 높음 (2) 2차전지 테마에 수급 집중 -> 다른 테마 말고 2차전지에만 집중
- **애프터마켓 급락 매매**: 금요일 애프터마켓 투매 시 삼성SDI 분할매수 -> 월요일 매도로 9,000만원 수익
- 다른 종목 합산 억대 수익

---

## 4. 핵심 매매 전략/교훈

1. **외국인/기관 대량 매수일 = 장 마감까지 강세**: 외국인+기관 수급 방향을 먼저 확인
2. **주도 테마에만 집중**: 2차전지가 압도적이면 다른 테마 매매하지 않기
3. **애프터마켓 급락 = 매수 기회**: 투매가 나올 때 분할매수로 진입, 반등 시 매도
4. **고객예탁금 체크**: 예탁금이 사상 최고 수준이면 조정 시 개인 매수세로 하방 지지 가능
