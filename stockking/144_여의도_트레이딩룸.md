# 144. 여의도 전업투자자 트레이딩룸

## 1. 영상 개요
- **한줄 요약:** 여의도에 위치한 전업투자자 홍인기의 트레이딩룸 소개 - 모니터 세팅, 허먼밀러 의자, 실전투자대회 금메달 등 전업투자자의 실제 환경 공개
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2023-11-10
- **영상 길이:** 6분 47초
- **원본 URL:** https://www.youtube.com/watch?v=4awWhnJtvk0

## 3. 주요 내용 정리

### [00:11~02:00] 트레이딩룸 위치 및 환경
- 여의도 신축 오피스텔 (2023년 8월 입주)
- 아버지도 전업투자자로 함께 사무실 사용
- 한강 조망 가능

### [02:00~03:55] 매매 장비 소개
- 큰 모니터 1대 + 서브 모니터 1대 (정보 과다 방지)
- 허먼밀러 의자 (당근마켓에서 120만원에 구매, 하루 종일 앉아있어 투자)
- 토프레 키보드, 계산기 상비

### [03:55~05:20] 매매 없을 때 대응
- 리클라이너 소파에서 휴식
- **매매할 게 없을 때 모니터 앞에 안 앉아 있으려고 함**
- 억지로 종목 찾으면 손실 발생하므로

### [05:20~06:47] 실전투자대회 수상
- 실전투자대회 상금을 금 명패로 수령 (999.9% 순금)
- 금을 투자로 생각하고 명패 형태로 보관

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 정보 과부하 방지 | 모니터 많으면 오히려 정신 없음 → 큰 모니터 1대로 집중 |
| 비매매 = 수익 보존 | 매매할 게 없으면 모니터에서 떨어져 억지 매매 방지 |
| 환경 투자 | 하루 종일 앉아있는 의자에 투자하는 것도 매매의 일부 |
