# 150. 실투대회 5회 수상자의 비기를 공개합니다

## 1. 영상 개요
- **한줄 요약:** 실전투자대회 5회 수상자가 거래대금을 동반한 장대양봉으로 전고점을 돌파하는 대박주 포착 전략을 공개 - 에코프로, 레인보우로보틱스, 코스모화학 등 실제 사례 분석
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2023-02-19
- **영상 길이:** 15분 53초
- **원본 URL:** https://www.youtube.com/watch?v=LAKy-6WnLC0

## 3. 주요 내용 정리

### [00:00~01:45] 대박주 패턴 소개
- 에코프로, 레인보우로보틱스, 코스모화학, 나노신소재, 포스코케미칼 공통 패턴
- **거래대금을 동반한 장대양봉으로 전고점 돌파**하는 종목이 지속 상승
- 강력한 매수세가 뒷받쳐주어 하락폭 제한, 상승 시 크게 상승

### [02:07~04:00] 조건 1: 거래대금 동반 장대양봉
- 전고점 돌파 또는 전고점에 가까워지는 장대양봉
- 거래대금 2,000억~6,000억 이상 동반 필수
- 차트만 보고 판단하면 절대 안 됨 - 여러 조건 종합 필요

### [04:02~07:34] 조건 2: 그날의 대장주여야 함
- 자신만의 힘으로 오른 대장주만 지속 상승 가능
- 따라오르는 2등주는 대장주 꺾이면 원래 자리로 복귀
- 코스모신소재(2등주) vs 코스모화학(대장주) 사례

### [07:34~11:00] 조건 3: 강력한 수급 (프로그램 매매)
- 외국인/기관 수급 없이 개인만으로 상승하는 종목은 급락 위험
- **모건스탠리 거래원에서 매수하는 종목**은 끝까지 매수하며 대박주 생성
- 한투/신한/JP모건은 단타 특성 강해 빠르게 이탈 가능
- 프로그램이 과열 구간에서도 매수 지속하면 추가 상승 신호

### [11:00~14:00] 조건 4: 시가총액 규모
- 최소 5,000억 이상 시가총액 필요
- 시총 클수록 외국인 장기 매집 확률 높음
- 에코프로 5.5조, 나노신소재 1.39조, 코스모화학 1.24조

### [12:27~15:51] 피해야 할 경우
- **키움증권 대량 매수 시** = 개인 주도 급등 = 고점 신호
- 키움 매수량이 매도량보다 10% 이상 많으면 주의
- **과열 기준**: 안 쉬고 2배 이상 상승 또는 이틀간 40% 이상 상승

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 거래대금 동반 장대양봉 | 전고점 돌파 + 대규모 거래대금 종목 공략 |
| 대장주 확인 | 자체 힘으로 상승하는 대장주만 매매 (2등주 회피) |
| 모건스탠리 수급 확인 | 모건스탠리 거래원 매수 종목은 지속 상승 확률 높음 |
| 시가총액 5,000억 이상 | 외국인 장기 매집 가능한 시총 규모 필요 |
| 과열 판단 기준 | 2배 이상 무쉬고 상승 또는 이틀간 40% 상승 시 주의 |
| 개인 주도 상승 경계 | 키움 매수 급증 = 고점 신호 |
