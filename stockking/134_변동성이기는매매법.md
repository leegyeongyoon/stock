## 3. 주요 내용 정리

**[00:00~01:44] 급락장 리뷰 (2024.08.05)**
- 코스피: 장중 -10% -> 마감 -8.77%
- 코스닥: 장중 -14% -> 마감 -11%
- 코로나 때보다 하루 낙폭이 더 큰 역대급 급락
- 코로나19 테마주는 변동성 속에서도 지속 강세

**[02:25~04:02] 급락장 대응 전략 - 단타 vs 중장기**
- 단타: 평소대로 주도 테마 대장주 공략 유지
- 급락장에서는 별도 자금으로 대형주 중장기 매수 기회 탐색
- 스윙/중장기 투자 자금을 따로 준비해두고 급락 시에만 투입

**[04:02~05:07] 계좌 분리 운영**
- 단타 계좌와 중장기 계좌를 별도 운영
- 분리 이유: 매수/매도 관점이 완전히 다름
- 같은 계좌에서 혼합하면 "단타 물려서 중장기" 식의 원칙 위반 발생
- 수익/손실 산출도 계좌별로 명확히 분리 가능

**[05:07~07:02] 단타와 중장기 투자 타이밍**
- 단타: 시장 상황 관계없이 계속 (조건에 맞는 종목 없으면 쉬면 됨)
- 중장기: 평소에는 안 하고, 지수가 정말 많이 떨어지고 신용반대매매 나올 때만 고려
- 중장기 기간은 고정이 아님: 빠르게 반등하면 빨리 매도, 느리면 오래 보유

**[07:02~09:26] 레버리지의 위험성**
- 급락장에서 레버리지 풀로 매수 -> 반등 성공 시 큰 수익
- 그러나 어쩌다 한번 반등 실패 시 한 번에 전부 상실 가능
- 추가 하락해도 버틸 수 있는 현금 매수는 괜찮지만, 레버리지는 반대매매 위험
- 수익보다 안정적으로 오래 살아남는 것에 집중

**[09:26~12:52] 주도 테마 대장주 매매의 장점**
- 주식 미보유가 디폴트 -> 큰 손실 회피가 최고 장점
- 소액으로도 수익 가능, 손실 금액도 작음
- 올라갈 종목 예상이 아닌, 시장에서 반응 나오는 종목을 매일 찾아 매매
- 주도 테마 없으면 쉬면 되기 때문에 안정적
- 실전 대응: 금요일 아침 잠시 매매 -> 시장 이상 감지 -> 매매 중단 -> 월요일 매매 안 함 -> 손실 zero

## 4. 핵심 매매 전략

| 전략 | 설명 |
|------|------|
| 계좌 분리 | 단타 계좌와 중장기 계좌를 분리 운영, 관점 혼동 방지 |
| 디폴트 현금 | 주식을 가지고 있지 않는 것이 기본 -> 큰 손실 회피 |
| 급락장 대응 | 단타는 원칙 유지, 중장기는 별도 자금으로 대형주 저가 매수 |
| 레버리지 배제 | 급락장 레버리지 매수는 한 번의 실패로 전부 상실 가능 -> 비추천 |
| 시장 감지 후 대응 | 시장이 이상하면 즉시 매매 중단, 반등 보고 다시 진입 |

## 6. 명언 / 핵심 문장

> "제가 주력으로 하는 주도 테마 대장주 매매의 장점은 주식을 가지고 있지 않는 것이 디폴트여서 큰 손실을 보지 않을 수 있는게 최고 장점입니다."

> "수익을 내는 것보다는 그냥 안정적으로 오래 살아남는 거에 집중을 해서 매매를 하고 있습니다."

> "내가 올라갈 종목을 예상해서 매매하는게 아니라 시장에서 반응이 나오는 종목을 매일매일 찾아다니면서 매매를 하기 때문에 가장 안정적인 매매법이라고 생각합니다."

> "예상과 다르게 더 하락하는 상황이 온다고 하더라도 버틸 수 있는 자금 내에서 무리하지 않고 매매를 하시면 또 다시 상승장이 왔을 때 수익을 낼 수 있습니다."

## 7. 체크리스트

- [ ] 단타 계좌와 중장기(스윙) 계좌를 분리하여 운영하고 있는가
- [ ] 주식 미보유를 디폴트로 하는 단기 매매를 하고 있는가
- [ ] 급락장에서 레버리지 사용을 자제하고 있는가
- [ ] 급락장 시 중장기 투자용 자금을 따로 준비해두었는가
- [ ] 시장이 이상하면 매매를 즉시 중단할 수 있는가
- [ ] 단타에서 물려서 중장기로 전환하는 원칙 위반을 하고 있지 않은가
- [ ] 버틸 수 있는 자금 범위 내에서만 매매하고 있는가
- [ ] 주도 테마가 보이지 않을 때 쉴 수 있는가
