# 143. 이노진 청약할까

## 1. 영상 개요
- **한줄 요약:** 코넥스 이전 상장 종목 이노진의 공모주 청약 분석 - 시장 분위기는 좋으나 코넥스 이전 상장 특성상 큰 기대는 어렵다는 판단
- **채널명:** 대왕개미 홍인기
- **업로드일:** 2023-02-08
- **영상 길이:** 3분 21초
- **원본 URL:** https://www.youtube.com/watch?v=GVa7NTdk2zU

## 2. 핵심 키워드
`#공모주` `#이노진` `#코넥스이전상장` `#따상` `#유통금액` `#시장분위기` `#균등청약` `#IBK투자증권` `#신규상장` `#수요예측`

## 3. 주요 내용 정리

### [00:00~00:48] 시장 분위기 및 최근 상장주 동향
- 코로나 유동성 장세급 거래대금 폭발
- 스튜디오미르 따상, 삼기EV, 오브젠, 미래반도체 등 신규 상장주 좋은 흐름
- MDS테크 거래대금 7,100억 급등, 에코프로 4,200억

### [00:48~01:12] 꿈비 및 제이오 청약 분석
- 꿈비: 유통금액 70억 역대급 소량 → 기대 종목
- 제이오: 시총 크고 유통금액 많지만 시장 분위기 덕에 참여 가능

### [01:12~02:44] 이노진 청약 분석
- 기관 경쟁률 1,603:1, 수요예측 양호
- 공모가 3,000원 / 코넥스 장외가 5,850원 (약 2배)
- 주관사: IBK 투자증권
- 균등 5~10주 배정 예상, 20주 청약 시 3만원 증거금
- 상장일: 2월 20일

### [02:44~03:21] 투자 판단
- 코넥스 이전 상장 종목은 일반적으로 좋은 결과 드묾
- 시장 분위기 힘입어 참여할 수 있으나 **큰 기대는 금물**

## 4. 핵심 매매 전략/교훈

| 전략 | 설명 |
|------|------|
| 시장 분위기 판단 | 공모주 성과는 시장 분위기에 크게 좌우됨 |
| 유통금액 체크 | 유통금액이 작을수록 상승 여력 큼 |
| 코넥스 이전 상장 주의 | 코넥스 이전 상장 종목은 성과가 좋지 않은 경우가 많음 |
| 균등 vs 비례 | 소액이면 균등 청약으로 참여 |
