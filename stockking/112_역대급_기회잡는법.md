## 3. 주요 내용 정리

### [00:00~03:00] 역대급 뉴스 판단법
- 동해 석유가스 매장 가능성 → 대통령 직접 발표 = 뉴스 세기 매우 강함
- 뉴스 판단 기준: (1) 뉴스가 강한가? (2) 지속 가능한 뉴스인가?
- 실제 결과가 아닌 기대감 상승 과정에서 매매해야 수익
- 대장주 한국석유 + 후발주 흥구석유 = 거래대금 상위 = 주도 테마 확인

### [03:00~07:00] 3일간 대장주 집중 매매 과정
- D+0(월요일): 한국석유 상따 → 후발주 6개 종목 상한가 → 오버나잇
- D+1(화요일): 갭 20% 상승 시작 → 시초가 추가 매수 + 1부 익절 → 연속 상한가 → 2억 오버나잇
- D+2(수요일): 갭상승 슈팅 때 전량 정리 + 장중 눌림매매 반복
- 3일 합계: 한국석유 약 9천만원 + 한국가스공사 약 1,600만원 = 총 1.24억 수익

### [07:00~12:00] 수익 극대화 팁
- 대장주 잡았으면 조금 올랐다고 팔지 말 것 → 테마 세기 유지 + 대장주 유지 = 버티기
- 일부 물량 저항선에서 수익 실현 → 심리적 안정 → 나머지 오래 버틸 수 있음
- 전량 보유 시 큰 하락에 심리 흔들려 저점 매도 위험

## 4. 핵심 매매 전략/교훈

1. **뉴스 판단: 강도 + 지속성 두 가지 확인** - 대통령 발표급 = 최고 강도
2. **대장주 확인 후 3일간 집중 매매** - 하루만 하고 끝내지 않기
3. **일부 분할매도로 심리적 안정 확보** - 전량 보유보다 버티기 수월
4. **후발주 상한가 다수 = 대장주 갭상승 기대** - 후발주 수 세기로 세기 판단
5. **조급함 경계** - 놓쳤어도 다음 기회 반드시 옴
